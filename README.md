# 🛍️ فروشگاه تلگرام + ربات‌های اپلودر

ربات مادر فروشگاه است، ربات‌های اپلودر فایل تحویل می‌دهند، پنل وب همه چیز را تنظیم می‌کند.
دو فایل PHP، بدون دیتابیس.

## فایل‌ها

| فایل | نقش |
|------|------|
| `bot_master_membership.php` | ربات مادر + ربات‌های اپلودر + منطق داده |
| `admin_panel.php` | پنل مدیریت وب |
| `MEMBERSHIP_SYSTEM_GUIDE.md` | راهنمای کامل فارسی |

## شروع سریع

1. `BOT_TOKEN` و `ADMIN_ID` و `CRON_KEY` را در فایل ربات تنظیم کنید
2. `ADMIN_PASSWORD` را در `admin_panel.php` عوض کنید
3. پنل → داشبورد → «تنظیم وبهوک ربات مادر»
4. کران هر دقیقه: `bot_master_membership.php?cron=کلید`

## قابلیت‌ها

**ربات مادر (فروشگاه)**
- منوی دکمه‌ای با ایموجی و رنگ قابل تنظیم — یا حالت شیشه‌ای
- خرید محصول با کیف پول یا پرداخت مستقیم با رسید
- حساب کاربری، افزایش موجودی، پیگیری سفارش
- زیر مجموعه گیری با پورسانت درصدی
- پشتیبانی ۱۰ روشه (مستقیم و غیرمستقیم)
- تایید سفارش فقط توسط ادمین

**ربات‌های اپلودر (عمومی)**
- آپلود فایل → ساخت لینک اشتراک
- قفل عضویت اجباری کانال‌ها قبل از تحویل
- حذف خودکار فایل بعد از N ثانیه
- محافظت از فوروارد و ذخیره
- آپلود تکی و گروهی، آمار کلیک و تحویل

**پنل وب** — ۱۰ تب: داشبورد، سفارش‌ها، محصولات، دکمه‌ها، متن‌ها، پشتیبانی، ربات‌ها، کانال‌ها، کاربران، تنظیمات

## امنیت

تایید سفارش فقط با `ADMIN_ID` · آپلود فقط توسط ادمین · CSRF روی همه فرم‌ها ·
`hash_equals` برای رمز · قفل عضویت **fail-closed** (ربات بدون دسترسی کانال، فایل نمی‌دهد)

پوشه `data_master/` شامل توکن ربات‌هاست — دسترسی عمومی به آن را ببندید.

# MyBOT — ربات ارسال بنر تلگرام (PHP)

ربات مدیریت و ارسال بنر برای گروه‌ها و کانال‌های خودتان، با پشتیبانی کامل از
**ایموجی پریمیوم**، **نقل‌قول (Quote)** — همان قابلیتی که تلگرام در Bot API 7.0
اضافه کرد — صف ارسال حرفه‌ای، و پنل آماری کامل.

بدون نیاز به Composer. فقط PHP 8.1+ با افزونه‌های `curl`، `pdo_sqlite` و `mbstring`.

---

## ⚠️ محدوده‌ی کاری این ربات

این ربات برای **جاهایی که خودتان مدیریت می‌کنید** ساخته شده است:

| مخاطب | توضیح |
|---|---|
| 👥 گروه‌ها و کانال‌ها | هر تعداد — ربات را عضو کنید، خودکار ثبت می‌شود |
| 👤 کاربران عضو ربات | فقط کسانی که خودشان `/start` زده‌اند و `/stop` نزده‌اند |

**چیزی که این ربات انجام نمی‌دهد:** استخراج لیست اعضای گروه‌ها و پیام خصوصی
انبوه به افرادی که خودشان به ربات پیام نداده‌اند، و ورود خودکار به چند اکانت
کاربری برای پخش بار ارسال. این کار طبق [شرایط استفاده تلگرام](https://telegram.org/tos)
اسپم محسوب می‌شود و نتیجه‌اش محدود شدن و بن شدن اکانت‌ها و خود ربات است.

قابلیت «اعضای پرفعالیت» در این ربات به‌صورت **آمار و گزارش** پیاده شده: ربات
پیام‌های گروه‌هایی که عضو آن است را می‌شمارد و جدول فعال‌ترین اعضا را نشان
می‌دهد — اما این فهرست هرگز به لیست گیرنده‌ی پیام خصوصی تبدیل نمی‌شود.

## نصب

```bash
git clone <repo> && cd MyBOT

cp config.php.example config.php
# توکن و آیدی ادمین را داخل config.php بگذارید

php bin/doctor.php     # بررسی سلامت
```

توکن را ترجیحاً از متغیر محیطی بدهید تا داخل هیچ فایلی نماند:

```bash
export BOT_TOKEN="123456:ABC..."
```

> `config.php` در `.gitignore` است و هرگز commit نمی‌شود. اگر توکنی لو رفت،
> فوراً در @BotFather دستور `/revoke` را بزنید.

### اجرا

دو پروسه جدا لازم است — این‌طور یک ارسال انبوه هیچ‌وقت پنل را کند نمی‌کند:

```bash
php bin/bot.php      # دریافت پیام‌ها و پنل مدیریت
php bin/worker.php   # ارسال صف
```

برای اجرای دائمی، نمونه‌ی systemd:

```ini
[Unit]
Description=MyBOT %i
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/MyBOT
Environment=BOT_TOKEN=123456:ABC...
ExecStart=/usr/bin/php /opt/MyBOT/bin/%i.php
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now mybot@bot mybot@worker
```

## تنظیم اولیه در BotFather

برای اینکه آمار «فعال‌ترین اعضا» کامل کار کند، ربات باید پیام‌های گروه را ببیند:

```
/setprivacy → Disable
```

سپس ربات را از گروه خارج و دوباره اضافه کنید تا تنظیم اعمال شود.

## قابلیت‌ها

### 🖼 بنرها

بنر را **دقیقاً همان‌طور که می‌خواهید ارسال شود** برای ربات می‌فرستید و ربات
عیناً همان را ذخیره می‌کند:

- ✨ **ایموجی پریمیوم** — به‌جای بازتولید متن با `parse_mode`، آرایه‌ی `entities`
  خام پیام شما ذخیره و موقع ارسال بازپخش می‌شود. هر ایموجی پریمیوم یک
  entity از نوع `custom_emoji` با `custom_emoji_id` است و دقیقاً حفظ می‌شود.
- 💬 **نقل‌قول (Quote)** — روی یک پیام ریپلای بزنید، بخشی از متنش را انتخاب و
  «Quote» را بزنید؛ ربات `quote`، `quote_entities` و `quote_position` را ذخیره
  می‌کند و موقع ارسال داخل `reply_parameters` بازپخش می‌کند.
- 📎 مدیا: عکس، ویدیو، گیف، فایل، صدا و ویس — با کپشن قالب‌دار
- 🔘 دکمه‌های شیشه‌ای: `متن دکمه | https://example.com` (هر خط یک دکمه، خط خالی = ردیف جدید)
- 🔒 قفل فوروارد و کنترل پیش‌نمایش لینک

> **نکته‌ی مهم درباره ایموجی پریمیوم:** طبق محدودیت خود تلگرام، فقط رباتی
> می‌تواند `custom_emoji` بفرستد که یک یوزرنیم از [Fragment](https://fragment.com)
> خریده باشد. ربات معمولی موقع ارسال خطا می‌گیرد — پنل این خطا را با توضیح
> فارسی نشان می‌دهد.

### 👥 گروه‌ها

- بدون محدودیت تعداد
- ربات را در گروه اضافه کنید → خودکار ثبت و فعال می‌شود
- یا داخل گروه: `/addgroup`
- یا با آیدی عددی از پنل
- پشتیبانی از **تاپیک‌های گروه‌های Forum** با `/settopic`
- اگر ربات از گروهی اخراج یا محدود شود، آن گروه خودکار غیرفعال می‌شود

### 📣 صف ارسال

- رعایت خودکار محدودیت‌های تلگرام (پیش‌فرض: ۲۵ پیام بر ثانیه، هر گروه هر ۳ ثانیه)
- مدیریت هوشمند خطاها:
  - `429 Too Many Requests` → صبر به‌اندازه‌ی `retry_after` (تلاش نمی‌سوزد)
  - خطای موقتی سرور → تلاش مجدد با backoff نمایی
  - کاربری که ربات را بلاک کرده → خودکار از لیست خارج
  - گروهی که ربات از آن اخراج شده → خودکار غیرفعال
- امکان لغو کمپین در حال اجرا
- چند worker هم‌زمان قابل اجراست (صف اتمیک claim می‌شود)
- اگر worker وسط کار بمیرد، پیام‌های نیمه‌کاره خودکار بازیابی می‌شوند

### 📊 آمار

- مخاطبان: عضو فعال، لغو عضویت، بلاک‌کرده، رشد ۲۴ ساعته
- ارسال: موفق/ناموفق ۲۴ ساعت و ۷ روز، نرخ موفقیت با نمودار متنی
- کمپین‌ها: پیشرفت زنده هر کمپین با نوار پیشرفت
- گروه‌ها: رتبه‌بندی بر اساس فعالیت و تعداد ارسال
- 🔥 فعال‌ترین اعضا: جدول هفتگی هر گروه + روند روزانه

## دستورها

**کاربر**

| دستور | کار |
|---|---|
| `/start` | عضویت و دریافت بنرها |
| `/stop` | لغو عضویت |
| `/id` | آیدی عددی |
| `/help` | راهنما |

**ادمین (خصوصی)**

| دستور | کار |
|---|---|
| `/panel` | پنل مدیریت |
| `/stats` | آمار کامل |
| `/send <id>` | ارسال سریع یک بنر |
| `/cancel` | لغو عملیات نیمه‌تمام |

**ادمین (داخل گروه)**

| دستور | کار |
|---|---|
| `/addgroup` | ثبت گروه فعلی |
| `/settopic` | ارسال در همین تاپیک |
| `/activity` | فعال‌ترین اعضای گروه |

## ساختار پروژه

```
bin/bot.php          دریافت آپدیت‌ها و پنل (long polling)
bin/worker.php       ارسال صف و کمپین‌های زمان‌بندی‌شده
bin/doctor.php       بررسی سلامت قبل از اجرا

src/App.php          سیم‌کشی سرویس‌ها
src/Handlers/        Router · Commands · Callbacks · Flows · Views
src/Service/         Banners · Targets · Users · Campaigns · Dispatcher
                     Sender · Activity · Stats · States
src/Support/         TelegramClient · Database · RateLimiter · Keyboards
                     Config · Logger · Text · ApiException

schema.sql           جدول‌های SQLite
tests/smoke.php      تست آفلاین (بدون نیاز به شبکه یا توکن)
```

## تست

```bash
php tests/smoke.php
```

۸۰ بررسی، بدون نیاز به توکن یا اینترنت — شامل حفظ ایموجی پریمیوم، بازپخش
نقل‌قول، تفکیک مدیا از متن، صف و کمپین، طبقه‌بندی خطاها و محدودکننده‌ی نرخ.

## تنظیم محدودیت‌ها

در `config.php` بخش `limits`. پیش‌فرض‌ها عمداً کمی محافظه‌کارانه‌تر از سقف رسمی
تلگرام هستند. بالا بردنشان باعث خطای ۴۲۹ و **کندتر شدن** کل صف می‌شود، نه سریع‌تر.

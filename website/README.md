# سایت نامبیکس (Numbix) — Galaxy Glass

سایت فارسی و راست‌به‌چپ نامبیکس برای اینماد. ظاهرش شیشه‌ای و کهکشانی است (بنفش، آبی، سبز، قرمز و سفید) و با یک تولیدکننده‌ی سایت ایستا (Python + Jinja) ساخته می‌شود.
در سایت هیچ دکمه، لینک یا ورودی به تلگرام نیست؛ نام کاربری ربات فقط در متن قوانین و حریم خصوصی آمده است.
خروجی فقط HTML/CSS/JS است. روی هاست نه PHP لازم است نه پایتون: در aaPanel سایت را **Static** بسازید.

## ساختار

```
website/
├── site.toml            ← همه‌ی اطلاعات کسب‌وکار، خدمات، وضعیت‌ها و اعلان‌ها (فقط همین را ویرایش کنید)
├── build.py             ← ساخت خروجی در dist/  (و پیش‌نمایش محلی)
├── numbix_site/         ← کد پایتون
│   ├── config.py        خواندن و یکدست‌کردن site.toml (اعداد فارسی، قیمت‌ها، شماره‌ها)
│   ├── pages.py         فهرست صفحه‌ها، آدرس‌ها و منوها
│   ├── assets.py        بسته‌بندی CSS/JS با نام هش‌دار + اسپرایت آیکن‌ها
│   ├── render.py        رندر صفحه‌ها، robots.txt و sitemap.xml
│   └── server.py        سرور پیش‌نمایش محلی
├── templates/
│   ├── base.html        پوسته‌ی مشترک همه‌ی صفحه‌ها
│   ├── macros/ui.html   کامپوننت‌ها: دکمه، کارت، بج، آمار، Empty State، تب، سوییچ و…
│   ├── partials/        هدر، سایدبار، ناوبری موبایل، فوتر، لودر، مودال و Toast
│   ├── layouts/         قالب صفحه‌های حقوقی (فهرست مطالب چسبان)
│   └── pages/           خانه، پنل، خدمات، درباره، تماس، قوانین، حریم خصوصی، ۴۰۴
└── assets/
    ├── css/             01-tokens (Design System) → 02-base → 03-galaxy → 04-layout → 05-components → 06-pages → 07-motion
    ├── js/              01-core → 02-galaxy (پس‌زمینه‌ی کانواس) → 03-ui (کامپوننت‌ها) → 04-app
    ├── icons/           آیکن‌های Lucide (فقط آیکن‌های استفاده‌شده وارد اسپرایت می‌شوند)
    ├── fonts/           وزیرمتن (روی سایت خودتان، بدون گوگل)
    └── img/favicon.svg
```

## ساخت و پیش‌نمایش

```bash
cd website
python3 -m venv .venv && . .venv/bin/activate   # یا روی اوبونتو:  sudo apt install python3-jinja2
pip install -r requirements.txt
python3 build.py --serve        # ساخت + پیش‌نمایش در http://127.0.0.1:8000
```

`python3 build.py --strict` اگر موردی در `site.toml` خالی مانده باشد خطا می‌دهد؛ قبل از آپلود نهایی از همین استفاده کنید.

## آپلود روی aaPanel

1. رکورد A دامنه و `www` را روی IP سرور بگذارید.
2. **Website ← Add site**، دامنه را وارد و PHP را روی **Static** بگذارید.
3. `index.html` و `404.html` پیش‌فرض aaPanel را پاک کنید (به `.user.ini` دست نزنید).
4. **محتوای** پوشه‌ی `dist/` را در ریشه‌ی سایت (`/www/wwwroot/دامنه`) آپلود کنید؛ یا روی خود سرور:
   ```bash
   python3 build.py --strict && cp -r dist/. /www/wwwroot/numbix.ir/
   ```
5. **SSL ← Let's Encrypt** و **Force HTTPS**.
6. در Config سایت: `error_page 404 /404.html;`

آدرس صفحه‌ها تمیز است (`/services/`، `/terms/` و…) و بدون تنظیم اضافه روی Nginx کار می‌کند.

## اینماد

- **کد تأیید دامنه:** مقدار `content` متا تگی را که اینماد می‌دهد در `[enamad] meta_code` بنویسید؛ فقط روی صفحه‌ی اصلی قرار می‌گیرد. اگر اینماد فایل داد، همان فایل را کنار `index.html` آپلود کنید.
- **نماد اعتماد:** کد کامل نماد را در `[enamad] seal_html` بچسبانید؛ در فوتر همه‌ی صفحه‌ها نمایش داده می‌شود.

چک‌لیست پیش از درخواست: دامنه‌ی ‎.ir به نام خود متقاضی در ایرنیک؛ نام، نشانی و کد پستی دقیقاً مطابق اطلاعات اینماد؛ `build.py --strict` بدون خطا؛ سایت با HTTPS و از اینترنت داخل ایران باز شود؛ اعداد بخش بازگشت وجه (۲۴ ساعت، ۳ روز کاری) با رویه‌ی واقعی شما یکی باشد.

## عملکرد

- سحابی‌ها و کهکشان مارپیچ یک بار نقاشی می‌شوند و فقط با CSS روی GPU حرکت می‌کنند. ستاره‌ها، شهاب‌ها، سنگ‌ها و نورهای شناور روی یک کانواس با یک حلقه‌ی `requestAnimationFrame` هستند؛ وقتی تب دیده نمی‌شود متوقف می‌شود و با ثابت‌بودن seed آسمان در همه‌ی صفحه‌ها یکسان می‌ماند.
- سه سطح کیفیت (`high` / `medium` / `low`) بر اساس دستگاه انتخاب می‌شود. اگر فریم‌ها کند شوند، سطح خودکار پایین می‌آید و در نهایت «حالت کم‌مصرف» روشن می‌شود (کاربر می‌تواند خاموشش کند).
- «حالت کم‌مصرف» در سایدبار، منوی حساب و منوی «بیشتر» موبایل هست: همه‌ی بلورها و حرکت‌های تزئینی را خاموش می‌کند. `prefers-reduced-motion` هم رعایت می‌شود.
- CSS و JS هر کدام یک فایل با نام هش‌دارند (کش طولانی بدون مشکل به‌روزرسانی). هیچ درخواست خارجی، کتابخانه یا کوکی ردیابی وجود ندارد.

## تغییر ظاهر

رنگ‌ها، شیشه، شعاع‌ها، فاصله‌ها، تایپوگرافی و زمان‌بندی انیمیشن‌ها همه در `assets/css/01-tokens.css` هستند. کامپوننت‌ها در `templates/macros/ui.html` تعریف شده‌اند و در همه‌ی صفحه‌ها همان‌ها استفاده می‌شوند.
آیکن جدید: فایل SVG آن را از [Lucide](https://lucide.dev) در `assets/icons/` بگذارید و با `{{ icon("name") }}` استفاده کنید.

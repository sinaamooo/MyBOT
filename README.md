# ربات تحلیلگر کانال (PHP)

ربات به **دایرکت کانال تلگرام** وصل می‌شود. وقتی کاربری می‌نویسد «تحلیل BTC»، چارت ارز را از صرافی می‌گیرد و تحلیل پرایس اکشن / اسمارت مانی انجام می‌دهد. نتیجه یک **عکس چارت تحلیلی** با کپشن کامل است (ورود، حد ضرر، تارگت‌ها، دلایل، نقدینگی، اخبار).

تحلیل در **کانالی که مدیر در `/panel` تنظیم می‌کند** منتشر می‌شود. به کاربر در دایرکت فقط اطلاع داده می‌شود که تحلیل منتشر شد، همراه با لینک پست. اگر کانالی تنظیم نشده باشد، تحلیل در خود دایرکت ارسال می‌شود.

## امکانات

- **موتور تحلیل (مغز ربات):** ساختار بازار (HH/HL/LH/LL)، شکست ساختار BOS و CHoCH، اوردر بلاک، FVG، زون‌های حمایت و مقاومت (با تایید تایم بالاتر)، نقدینگی (BSL/SSL و سقف و کف‌های برابر)، دیوارهای اوردربوک، EMA 20/50/200، RSI و واگرایی، MACD و حجم. همه در سه تایم‌فریم بررسی می‌شوند.
- **Gemini:** خروجی موتور، کندل‌های خام و تصویر چارت به Gemini داده می‌شود. Gemini سناریو و نقطه ورود، حد ضرر و تارگت‌ها را نهایی می‌کند و متن فارسی می‌نویسد. ربات اعداد Gemini را **اعتبارسنجی** می‌کند (حد ضرر سمت درست باشد، تارگت‌ها مرتب باشند، ریسک منطقی باشد و ...). اگر پلن Gemini غلط باشد، پلن خود موتور استفاده می‌شود.
- **عکس چارت:** پس‌زمینه مشکی، کندل صعودی سفید و نزولی قرمز، حمایت و مقاومت با خط نقطه‌چین `........`، سطح ۵۰٪ اوردر بلاک‌ها با خط‌چین آبی آسمانی `-------` و برچسب «50% OB»، نقدینگی، BOS/CHoCH و **مسیر احتمالی قیمت** (سبز پررنگ برای صعودی، قرمز پررنگ برای نزولی). همه متن‌ها در کپشن هستند.
- **اخبار:** تیترهای مرتبط از RSS سایت‌های Cointelegraph، CoinDesk و Decrypt (اگر Gemini فعال باشد ترجمه فارسی با برچسب مثبت یا منفی).
- **محدودیت‌ها:** هر کاربر ۲ تحلیل در هفته (هفته از شنبه شروع می‌شود). تحلیل فقط **شنبه و یکشنبه** انجام می‌شود. هر دو از `config.php` قابل تغییرند. تحلیل ناموفق از سهمیه کم نمی‌شود.
- پیام‌های غیر تحلیلی دایرکت (مثل سلام و سوال) جواب داده نمی‌شوند تا خودتان جواب بدهید.
- اطلاعات بازار از Binance می‌آید و اگر در دسترس نباشد، به ترتیب از Bybit، OKX و KuCoin (بدون نیاز به API key).

## نسخه تک‌فایلی (ساده‌ترین روش)

```bash
php tools/build.php        # خروجی: dist/bot.php و dist/config.php
```

1. هر دو فایل را در یک پوشه روی هاست آپلود کنید و `config.php` را پر کنید.
2. لینک وب‌هوک همان آدرس `bot.php` است، مثلاً `https://yourdomain.com/bot/bot.php`.
3. برای فعال‌سازی این آدرس را در مرورگر باز کنید: `https://yourdomain.com/bot/bot.php?setup=<webhook_secret>`. این صفحه هاست را بررسی می‌کند و وب‌هوک را خودکار ست می‌کند.

فونت‌ها در اولین اجرا خودکار دانلود می‌شوند. پوشه داده (دیتابیس، لاگ، عکس‌ها) هم خودکار ساخته می‌شود.

## نصب (نسخه چندفایلی)

### ۱) هاست

- PHP نسخه 8.0 یا بالاتر با افزونه‌های `curl`، `gd` (با FreeType)، `mbstring`، `pdo_sqlite` و `simplexml`
- دامنه با **HTTPS**
- **هاست باید خارج از ایران باشد.** API تلگرام، صرافی‌ها و Gemini از سرورهای ایران در دسترس نیستند. یک هاست اشتراکی یا VPS اروپایی کافی است. برای VPS، گزینه `market.proxy` هم وجود دارد.

### ۲) آپلود و تنظیمات

1. همه فایل‌ها را در یک پوشه روی هاست آپلود کنید (مثلاً `public_html/bot`).
2. فایل `config.example.php` را کپی کنید و اسمش را `config.php` بگذارید. بعد این موارد را پر کنید:
   - `bot_token`: توکن ربات از BotFather
   - `admin_ids`: آیدی عددی مدیر (از قبل `6595849261` گذاشته شده)
   - `webhook_secret`: یک رشته تصادفی طولانی
   - `webhook_url`: آدرس کامل فایل `webhook.php`، مثلاً `https://yourdomain.com/bot/webhook.php`
   - `gemini.api_key`: کلید Gemini
   - `brand`: اسم و آیدی کانال (روی عکس‌ها نوشته می‌شود)
3. به پوشه `storage` دسترسی نوشتن بدهید (`chmod 775 storage`).

> `config.php` در `.gitignore` است. توکن و کلید را هیچ‌وقت داخل گیت‌هاب نگذارید.

### ۳) بررسی و فعال‌سازی

با SSH:

```bash
php tools/check.php          # بررسی PHP، افزونه‌ها، توکن، دسترسی به صرافی و Gemini
php tools/set_webhook.php    # وصل کردن webhook
```

بدون SSH (در مرورگر، `SECRET` همان `webhook_secret` است):

```
https://yourdomain.com/bot/tools/check.php?key=SECRET
https://yourdomain.com/bot/tools/set_webhook.php?key=SECRET
```

### ۴) اتصال به دایرکت کانال

1. در تنظیمات کانال، **Direct Messages** را روشن کنید.
2. ربات را **ادمین کانال** کنید و دسترسی **مدیریت پیام‌های مستقیم (Manage Direct Messages)** را به آن بدهید.
3. از یک اکانت عادی به دایرکت کانال بنویسید: `تحلیل BTC`

## استفاده کاربران

- `تحلیل BTC` (تایم پیش‌فرض ۴ ساعته)
- `تحلیل ETH 1h` و `تحلیل سولانا روزانه` و `BTC h4`
- تایم‌فریم‌ها: 15m، 30m، 1h، 2h، 4h، 6h، 12h، 1d، 1w
- `سهمیه`: تعداد تحلیل باقی‌مانده
- `راهنما`

## پنل مدیریت: `/panel`

در چت خصوصی با ربات `/panel` را بفرستید. این تنظیمات از همان‌جا با دکمه عوض می‌شوند:

- **کانال انتشار:** دکمه «تنظیم کانال» را بزنید و آیدی کانال (`@channel`) را بفرستید یا یک پیام از کانال فوروارد کنید. ربات باید در آن کانال ادمین باشد و اجازه ارسال پیام داشته باشد.
- **روشن و خاموش کردن ربات**
- **سهمیه هر کاربر** با دکمه‌های ➕ و ➖
- **روزهای تحلیل:** روشن یا خاموش کردن هر روز هفته
- **روشن و خاموش کردن Gemini**
- **اطلاع‌رسانی در دایرکت** بعد از انتشار تحلیل در کانال
- **آمار**

## دستورات مدیر (در چت خصوصی با ربات)

| دستور | کار |
|---|---|
| `/panel` | پنل تنظیمات |
| `/test BTC 4h` | تحلیل فوری در همین چت، بدون محدودیت روز و سهمیه |
| `/stats` | آمار |
| `/user 123` یا `/user @username` | وضعیت یک کاربر |
| `/addquota 123 2` | سهمیه اضافه |
| `/reset 123` | صفر کردن سهمیه این هفته |
| `/ban 123` / `/unban 123` | مسدود یا آزاد کردن |
| `/off` / `/on` | توقف یا فعال‌سازی ربات |
| `/brain متن` | آموزش سبک تحلیل به Gemini (مثلاً «تارگت‌ها را روی نقدینگی بگذار») |
| `/brain` و `/brain_clear` | نمایش یا پاک کردن آموزش‌ها |

## آموزش دادن به مغز ربات

- **وزن فاکتورها:** فایل `brain/strategy.php`. مثلاً می‌توانید اهمیت روند تایم بالا یا واگرایی RSI را کم و زیاد کنید.
- **اندیکاتور اختصاصی:** نمونه در `brain/indicators/_example.php` هست. فایل را کپی کنید، اسمش را بدون `_` بگذارید (مثلاً `my_indicator.php`) و منطق اندیکاتور را بنویسید. خروجی آن یک امتیاز و یک دلیل فارسی است و در تحلیل حساب می‌شود. (اندیکاتورهایی را که برایم بفرستید همین‌جا اضافه می‌کنم.)
- **سبک نوشتن و قوانین Gemini:** دستور `/brain` در تلگرام.

## تست بدون تلگرام

```bash
php tools/demo.php BTC 4h          # با داده واقعی صرافی
php tools/demo.php BTC 4h --demo   # با داده ساختگی، بدون اینترنت
php tools/selftest.php             # شبیه‌سازی پیام‌های تلگرام (هیچ پیامی ارسال نمی‌شود)
```

عکس خروجی در `storage/out/` ذخیره می‌شود.

## اجرا روی VPS بدون webhook

```bash
php poll.php --delete-webhook
```

## ساختار پروژه

```
webhook.php            ورودی تلگرام
poll.php               اجرای long polling
config.example.php     نمونه تنظیمات
brain/                 مغز ربات (وزن‌ها و اندیکاتورهای اختصاصی)
src/Bot.php            منطق ربات، سهمیه، روزها، دستورات مدیر
src/AnalysisService.php  موتور تحلیل، Gemini، اعتبارسنجی، چارت و کپشن
src/Analysis/          اندیکاتورها، ساختار بازار، زون‌ها، اوردر بلاک، نقدینگی
src/Market/            داده صرافی‌ها و اخبار
src/Ai/Gemini.php      اتصال به Gemini
src/Render/            رسم چارت (GD) و ساخت کپشن
assets/fonts/          فونت وزیرمتن (OFL)
```

> این ربات ابزار آموزشی است و تحلیل‌هایش توصیه مالی نیست.

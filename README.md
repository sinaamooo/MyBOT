# 🛍️ سیستم خرید و فروش اعضای تلگرام

**نسخه حرفه‌ای - 3 فایل PHP جامع**

```
✅ ربات اصلی + مدیریت ربات‌های فرعی
✅ دکمه‌های شیشه‌ای (آبی، قرمز، سبز)
✅ ایموجی‌های Premium
✅ سیستم خرید و فروش
✅ مدیریت کاربران
✅ پنل ادمین جامع
✅ درصد سود (Profit %)
✅ روش‌های واریز (تتر، ترون، تومی)
✅ قفل/باز کردن کانال‌ها
✅ ذخیره داده JSON (بدون دیتابیس)
```

## ✨ ویژگی‌های جزئی

### 🤖 ربات اصلی
- منوی شیشه‌ای با دکمه‌های رنگی
- دستورات: /start, /balance, /help
- سیستم خرید اعضا
- سیستم فروش اعضا
- تاریخچه تراکنش‌ها
- تنظیمات (شماره، روش پرداخت، کیف پول)

### 💳 سیستم پرداخت
- تتر (USDT)
- ترون (TRX)  
- تومی
- درصد سود خودکار (10%)

### 🔐 پنل مدیریت
- نمایش آمار کاربران
- مدیریت خریدها و فروش‌ها
- مدیریت ربات‌های فرعی
- مدیریت کانال‌های اجباری
- گزارش‌های جزئی

### 🎨 طراحی
- دکمه‌های شیشه‌ای (Glassy)
- ایموجی‌های Premium روی دکمه‌ها و متن‌ها
- سه رنگ: آبی🔵 قرمز🔴 سبز🟢
- رابط‌کاربری جذاب

## 🚀 نصب (خیلی آسان!)

### 1️⃣ آپلود فایل‌ها
```
yourdomain.com/
├── bot.php       (ربات)
├── setup.php     (تنظیم)
├── admin.php     (مدیریت)
└── data/         (خودکار ایجاد می‌شود)
```

### 2️⃣ رفتن به Setup
```
https://yourdomain.com/setup.php
```

### 3️⃣ کلیک کنید و انجام دهید
- ✅ تست ربات
- ✅ وارد کردن URL webhook
- ✅ تنظیم و تمام!

## 📁 فایل‌ها

| فایل | توضیح |
|------|--------|
| `bot.php` | ربات تلگرام (webhook handler) |
| `setup.php` | صفحه تنظیم webhook |
| `admin.php` | پنل مدیریت |
| `data/` | پوشه ذخیره داده‌ها |

## 🎮 دستورات ربات

| دستور | توضیح |
|-------|--------|
| `/start` | منوی اصلی |
| `/balance` | نمایش موجودی |
| `/help` | راهنمای سیستم |

## 💬 استفاده

**خرید اعضا:**
- منوی اصلی → خرید اعضا
- تعداد اعضا را وارد کنید (مثل 100)
- تأیید از مدیر

**فروش اعضا:**
- منوی اصلی → فروش اعضا
- فرمت: `تعداد قیمت` (مثل 100 50)
- سود خودکار محاسبه می‌شود

**تنظیمات:**
- منوی اصلی → تنظیمات
- شماره تلفن
- روش پرداخت (تتر/ترون/تومی)
- آدرس کیف پول

## 🔐 پنل مدیریت

```
URL: https://yourdomain.com/admin.php
Admin ID: 8213021584
Password: (آن چیزی که تنظیم کنید)
```

نمایش:
- 📊 آمار کاملی از کاربران و تراکنش‌ها
- 👥 لیست کاربران با موجودی
- 🛍️ خریدها (در انتظار/تکمیل)
- 💰 فروش‌ها و درآمد
- 🤖 ربات‌های فرعی
- 📢 کانال‌های اجباری

## 📊 داده‌های شما

تمام داده‌ها در JSON ذخیره می‌شود:
```
data/users.json          (کاربران)
data/purchases.json      (خریدها)
data/sales.json         (فروش‌ها)
data/subbots.json       (ربات‌های فرعی)
data/channels.json      (کانال‌ها)
```

## 🆘 مشکل گیری

**مشکل:** ربات متصل نمی‌شود
```
حل: setup.php میروید و تست اتصال را کلیک کنید
```

**مشکل:** Webhook کار نمی‌کند
```
حل: 
- دامنه شما HTTPS باشد
- آدرس درست وارد شده باشد
- از setup.php دوباره تلاش کنید
```

**مشکل:** داده‌ها ذخیره نمی‌شوند
```
حل: پوشه data/ باید قابل نوشتن باشد
chmod 755 data/
```

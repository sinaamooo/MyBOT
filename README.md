## 🚀 نصب (خیلی آسان!)

### 1️⃣ آپلود فایل‌ها
```
yourdomain.com/
├── bot.php       (ربات)
├── setup.php     (تنظیم)
├── admin.php     (مدیریت)
└── data/         (خودکار ایجاد می‌شود)
```

### 2️⃣ رفتن به Setup
```
https://yourdomain.com/setup.php
```

### 3️⃣ کلیک کنید و انجام دهید
- ✅ تست ربات
- ✅ وارد کردن URL webhook
- ✅ تنظیم و تمام!

# ربات سیگنال خودکار تلگرام (کریپتو)

ربات سیگنال فیوچرز ارز دیجیتال با PHP. بازار را خودش اسکن می‌کند، ستاپ‌ها را با ترکیب چند
ماژول تحلیلی می‌سنجد، بهترین سیگنال را با کارت تصویری به کانال می‌فرستد و معامله را تا آخر
(تارگت‌ها، ریسک‌فری، حد ضرر) خودش مدیریت و اعلام می‌کند. روی هاست اشتراکی معمولی (cPanel)
اجرا می‌شود و دیتابیس جدا لازم ندارد.

---

## امکانات

- اسکن خودکار ارزهای پرحجم فیوچرز از چند صرافی و منبع داده (MEXC، Binance، Bybit، OKX،
  KuCoin، Gate، Bitget، HTX، CryptoCompare) — برای داده بازار کلید API لازم نیست
- تحلیل ترکیبی روی تایم‌فریم‌های 15m / 30m / 1h / 2h با تایید تایم بالاتر
- فقط کندل‌های بسته‌شده تحلیل می‌شوند (بدون سیگنال فیک وسط کندل)
- اهرم خودکار بر اساس نقدینگی و نوسان هر ارز، چهار تارگت و حد ضرر ساختاری
- کارت تصویری شیشه‌ای و ساده برای سیگنال و همه نتیجه‌ها (شات سود، حد ضرر، بدون ضرر، پایان زمان)
- مدیریت کامل معامله: ریسک‌فری بعد از تارگت ۱، حد ضرر پله‌ای، بستن خودکار معامله‌ی کهنه
- سقف روزانه سیگنال و ضرر، سقف معامله باز، فاصله‌ی حداقلی بین سیگنال‌ها
- پنل مدیریت کامل داخل تلگرام (همه تنظیمات بدون ویرایش فایل)
- یک دکمه شیشه‌ای رنگی زیر همه پست‌های کانال
- حفظ کامل فرمت متن‌ها (Quote، بولد، ایموجی پریمیوم)

---

## پیش‌نیازها

- PHP 8.1 یا بالاتر با افزونه‌های `curl`، `pdo_sqlite`، `mbstring`
- افزونه `gd` برای کارت‌های تصویری (بدون آن فقط متن ارسال می‌شود)
- دامنه با SSL (برای وبهوک تلگرام)
- امکان ساخت Cron Job

## فایل‌ها

| فایل | کار |
|---|---|
| `config.php` | تنظیمات، دیتابیس SQLite، لاگ |
| `signal.php` | صرافی‌ها، اندیکاتورها، استراتژی، پلن معامله |
| `card.php` | ساخت کارت‌های تصویری |
| `bot.php` | کلاینت تلگرام، پنل مدیریت، وبهوک |
| `worker.php` | حلقه اصلی: اسکن، سیگنال، ارسال، مدیریت معامله |

| `env.example.php` | نمونه تنظیمات |
| `Manrope-*.ttf` | فونت کارت‌ها (لایسنس در `Manrope-OFL.txt`) |
| `Vazirmatn-*.ttf` | فونت متن فارسی روی کارت (لایسنس در `Vazirmatn-OFL.txt`) |

## نصب

۱. همه فایل‌ها را در یک پوشه روی هاست آپلود کنید (مثلاً `public_html/signalbot`).

۲. `env.example.php` را به `env.php` کپی کنید و این دو را پر کنید:

```php
'TELEGRAM_BOT_TOKEN' => 'توکن ربات از BotFather',
'ADMIN_IDS' => 'آیدی عددی تلگرام شما',
```

۳. در مرورگر `https://yourdomain.com/signalbot/setup.php` را باز کنید. همه چیز را چک می‌کند و با
دکمه «ثبت وبهوک» وبهوک را خودکار ثبت می‌کند.

۴. Cron Job هر دقیقه بسازید (بخش بعد).

۵. ربات را ادمین کانال کنید، در تلگرام `/panel` بزنید و از «کانال‌ها» آیدی عددی کانال را اضافه
و فعال کنید.

۶. `setup.php` را پاک کنید.

پوشه `storage/` خودکار ساخته می‌شود و با `.htaccess` از دسترسی وب محافظت می‌شود:

| فایل | محتوا |
|---|---|
| `texts.json` | همه متن‌های «مدیریت متن‌ها» و تنظیمات دکمه کانال |
| `database.sqlite` | کندل‌ها، سیگنال‌ها، کانال‌ها و تنظیمات پنل |
| `worker.lock` | قفل اجرای هم‌زمان worker |

`texts.json` جدا از دیتابیس است؛ برای بکاپ متن‌ها همین یک فایل کافی است. دیتابیس هر ۲۴ ساعت
خودکار تمیز و فشرده می‌شود (کندل‌های کهنه، سابقه اسکن‌ها و ناحیه‌های قدیمی حذف می‌شوند).
`env.php` در `.gitignore` است و نباید در مخزن کامیت شود.

## Cron Job

در cPanel بخش **Cron Jobs**، همه‌ی زمان‌ها (Minute، Hour، Day، Month، Weekday) را روی
«Every …» بگذارید و در فیلد **Command** فقط این را بنویسید (بدون `* * * * *`):

```
/usr/local/bin/php /home/USERNAME/public_html/signalbot/worker.php >> /home/USERNAME/public_html/signalbot/worker_cron.log 2>&1
```

مسیر PHP روی هر هاست فرق دارد (مثلاً `/opt/cpanel/ea-php82/root/usr/bin/php`). مسیر دقیق
`worker.php` را خود `setup.php` و پیام «وضعیت سیستم» پنل نشان می‌دهند.

## پنل مدیریت (`/panel`)

| بخش | کار |
|---|---|
| صرافی‌ها | روشن/خاموش کردن صرافی‌ها |
| کانال‌ها | افزودن کانال، فعال‌سازی، Quote، حداقل امتیاز هر کانال |
| Scanner | تست اتصال صرافی‌ها، اسکن دستی، فیلتر حجم و اسپرد |
| مدیریت متن‌ها | ویرایش متن سیگنال و همه اعلام‌ها با فرمت کامل |
| اتومات | وضعیت زنده، معاملات باز، کارنامه، و همه تنظیمات در ۵ دسته |
| Test Signal | سیگنال آزمایشی و تست ارسال روی کانال |
| وضعیت سیستم | سلامت worker، صرافی‌ها و آخرین خطاها |
| دکمه‌های کانال | متن، لینک، رنگ و آیکون دکمه زیر پست‌ها |

هر تنظیمی که از پنل عوض شود روی `env.php` اولویت دارد و بلافاصله اعمال می‌شود (تنظیمات
اسکنر بعد از «اسکن الان»). فرستادن «حذف» به‌جای مقدار، آن را به مقدار `env.php` برمی‌گرداند.

## تنظیمات مهم

| کلید | پیش‌فرض | کار |
|---|---|---|
| `SIGNAL_TIMEFRAMES` | `15m,30m,1h,2h` | تایم‌فریم‌های تحلیل |
| `MIN_CONFLUENCE_SCORE` | `80` | حداقل امتیاز هم‌گرایی برای انتشار |
| `MAX_DAILY_SIGNALS` | `10` | سقف سیگنال روزانه |
| `MAX_DAILY_LOSSES` | `5` | بعد از این تعداد ضرر، تا فردا سکوت |
| `MAX_OPEN_TRADES` | `3` | حداکثر معامله باز هم‌زمان |
| `MIN_SIGNAL_GAP_MINUTES` | `30` | حداقل فاصله بین دو سیگنال |
| `MAX_TRADE_HOURS` | `24` | اگر تا این مدت به تارگت ۱ نرسد، بسته می‌شود |
| `SYMBOL_LOSS_COOLDOWN_SECONDS` | `10800` | استراحت یک ارز بعد از حد ضرر |
| `LEVERAGE_MAJOR` | `15` | اهرم BTC و ETH |
| `LEVERAGE_ALT_MIN` / `MAX` | `8` / `25` | بازه اهرم آلت‌کوین‌ها |
| `TP1..TP4_LEVERAGED_PCT` | `28/50/90/160` | تارگت‌ها به درصد سود با اهرم |
| `MAX_STOP_LEVERAGED_PCT` | `35` | سقف ضرر با اهرم |
| `TP1_CLOSE_PERCENT` | `50` | درصد خروج در تارگت ۱ |
| `MAX_OPPOSING_VOTE_RATIO` | `0.6` | رد بازار دوطرفه (1 یعنی خاموش) |
| `REQUIRE_BREAKOUT_MOMENTUM` | `true` | شکست بدون تایید مومنتوم/حجم رد شود |
| `TRADABLE_VENUES` | `toobit,ourbit` | فقط ارزهای لیست‌شده در این صرافی‌ها (خالی = همه) |
| `MIN_VOLUME_USDT` | `5000000` | حداقل حجم ۲۴ ساعته |
| `RUN_MODE` | `LIVE` | `DRY_RUN` برای تست بدون ارسال |
| `CARD_BRAND` | `AUTO TRADE MARKET` | نام برند روی کارت‌ها |

## چرخه معامله

```
باز ── حد ضرر ────────────────────────────► بسته (ضرر)
 ├──── ۲۴ ساعت بدون تارگت ۱ ───────────────► بسته (زمان)
 └──── تارگت ۱: ۵۰٪ خروج + ریسک‌فری
          ├── برگشت به ورود ───────────────► بسته (بدون ضرر)
          └── تارگت ۲: حد ضرر روی تارگت ۱
                 └── تارگت ۳: حد ضرر روی تارگت ۲
                        └── تارگت ۴ ───────► بسته (سود کامل)
```

هر مرحله با ریپلای روی همان سیگنال در کانال اعلام می‌شود.

## منطق استراتژی

هر ستاپ از شش گروه مستقل امتیاز می‌گیرد: ساختار (BOS/CHoCH، شکست رنج)، نقدینگی (جارو،
بریکر بلاک)، ناحیه (اوردر بلاک، FVG، حمایت/مقاومت، OTE)، مومنتوم (MACD، سوپرترند، RSI)،
حجم، و روند بالاتر (EMA200، تایم بالاتر). سقف هر گروه جداست تا چند نشانه‌ی شبیه به هم
امتیاز را الکی بالا نبرند.

قبل از انتشار، ستاپ باید از این فیلترها رد شود: هم‌جهتی با روند، نبودن سطح قوی مخالف،
دنبال نکردن حرکت تمام‌شده، وجود ناحیه‌ی محافظ برای حد ضرر، تایید کندل برگشتی روی 5m برای
ورودهای پولبکی، هم‌جهتی تایم بالاتر، فضای کافی تا هدف، دوطرفه نبودن بازار، و تایید مومنتوم
برای شکست‌ها.

## متن‌ها، ایموجی پریمیوم و دکمه

- در «مدیریت متن‌ها» پیامی بفرستید که دقیقاً همان شکلی باشد که می‌خواهید؛ Quote، بولد و
  ایموجی پریمیوم همان‌طور ذخیره و ارسال می‌شوند. placeholderها (`{symbol}`، `{entry}` و…)
  را دست‌نخورده بگذارید.
- تلگرام ایموجی پریمیوم (و آیکون پریمیوم دکمه) را در کانال فقط برای رباتی قبول می‌کند که
  یوزرنیم خریداری‌شده از Fragment داشته باشد. اگر رد شود، ربات خودکار بدون آن می‌فرستد.
- «دکمه‌های کانال»: متن، لینک، رنگ (سبز/آبی/قرمز) و آیکون دکمه زیر همه پست‌ها.
- لوگوی خودتان: فایل `logo.png` را کنار فایل‌ها بگذارید.

## عیب‌یابی

- **ربات به `/start` جواب نمی‌دهد:** `setup.php` را باز کنید؛ دقیقاً می‌گوید کدام مرحله خراب
  است (توکن، وبهوک، دسترسی‌ها).
- **باز کردن `bot.php` در مرورگر خطای 400 یا 403 می‌دهد:** طبیعی است؛ این آدرس فقط درخواست
  تلگرام را قبول می‌کند.
- **«Worker: هرگز اجرا نشده»:** Cron Job ثبت نشده یا مسیرش اشتباه است.
- **cPanel خطای `bad command` می‌دهد:** `* * * * *` را داخل فیلد Command ننویسید.
- **سیگنال نمی‌آید:** پنل ← اتومات؛ خط بالای صفحه دلیل را می‌گوید (سقف روزانه، سقف معامله
  باز، فاصله بین سیگنال‌ها، یا بهترین ستاپ و علت رد شدنش).

---

## هشدار

این ربات ابزار تحلیل است، نه توصیه مالی. معامله با اهرم ریسک بالایی دارد و نتیجه‌ی گذشته
تضمینی برای آینده نیست. قبل از استفاده واقعی، مدتی با `RUN_MODE = DRY_RUN` یا حساب کوچک
تست کنید.

# 🛍️ سیستم فروش ممبرشیپ تلگرام

ربات مادر عضویت می‌فروشد، ربات‌های فرعی فایل تحویل می‌دهند، پنل وب همه چیز را مدیریت می‌کند.
دو فایل PHP، بدون دیتابیس، بدون کتابخانه بیرونی.

## فایل‌ها

| فایل | نقش |
|------|------|
| `bot_master_membership.php` | ربات مادر + ربات‌های فرعی + منطق داده |
| `admin_panel.php` | پنل مدیریت وب |
| `MEMBERSHIP_SYSTEM_GUIDE.md` | راهنمای کامل فارسی |

## شروع سریع

1. هر دو فایل PHP را کنار هم روی هاست بگذارید (PHP 8.0+)
2. در `bot_master_membership.php` مقدار `BOT_TOKEN` و `ADMIN_ID` را بگذارید
3. در `admin_panel.php` مقدار `ADMIN_PASSWORD` را عوض کنید
4. `admin_panel.php` را باز کنید → داشبورد → «تنظیم وبهوک ربات مادر»
5. یک ممبرشیپ و یک ربات اپلودری اضافه کنید

جزئیات کامل در [`MEMBERSHIP_SYSTEM_GUIDE.md`](MEMBERSHIP_SYSTEM_GUIDE.md).

## قابلیت‌ها

- فروش چند ممبرشیپ با قیمت‌های USDT / TRX / تومان
- محدودیت تعداد اعضا برای هر ممبرشیپ
- پرداخت با رسید (عکس یا TxID) و **تایید فقط توسط ادمین**
- لینک دسترسی اختصاصی گره‌خورده به آیدی کاربر
- ربات‌های فرعی اپلودر: آپلود تکی و گروهی، آمار، پیام همگانی
- پنل وب: داشبورد، تایید پرداخت، مدیریت اعضا و ربات‌ها، مسدودسازی
- پنل ادمین داخل تلگرام با `/panel`
- دکمه‌های رنگی 🟢🔴🔵
- نوشتن اتمیک و قفل‌دار روی فایل‌های JSON

## امنیت

- تایید پرداخت فقط با `ADMIN_ID` — از تلگرام یا پنل وب
- لینک دسترسی فقط با حساب صادرشده کار می‌کند
- حذف عضو، لینکش را باطل می‌کند
- محافظت CSRF روی همه فرم‌های پنل
- مقایسه رمز با `hash_equals`

پوشه `data_master/` شامل توکن ربات‌هاست — دسترسی عمومی به آن را ببندید.

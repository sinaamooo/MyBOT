# 🛍️ سیستم خرید و فروش اعضای تلگرام

**نسخه حرفه‌ای - 4 فایل PHP جامع**

```
✅ ربات اصلی + مدیریت ربات‌های فرعی
✅ دکمه‌های شیشه‌ای (آبی، قرمز، سبز)
✅ ایموجی‌های Premium
✅ سیستم خرید و فروش
✅ مدیریت کاربران
✅ پنل ادمین جامع
✅ درصد سود خودکار (Profit % = 10%)
✅ روش‌های واریز (تتر، ترون، تومی)
✅ سیستم کانال‌های اجباری
✅ محدود کردن/رفع محدودیت کاربران
✅ توابع API برای ربات‌های فرعی
✅ ذخیره داده JSON (بدون دیتابیس)
```

## ✨ ویژگی‌های جزئی

### 🤖 ربات اصلی
- منوی شیشه‌ای با دکمه‌های رنگی (آبی، قرمز، سبز)
- دستورات: `/start`, `/balance`, `/help`
- سیستم خرید اعضا (درخواست، تأیید، تکمیل)
- سیستم فروش اعضا (قیمت‌گذاری، سود خودکار)
- تاریخچه تراکنش‌ها و سفارش‌ها
- تنظیمات (شماره تلفن، روش پرداخت، آدرس کیف پول)

### 💳 سیستم پرداخت
- تتر (USDT)
- ترون (TRX)  
- تومی
- درصد سود خودکار (10%)

### 🔐 پنل مدیریت
- داشبورد آماری جامع (کاربران، خریدها، درآمد، فروش‌ها)
- مدیریت کاربران (لیست، موجودی، روش پرداخت)
- مدیریت خریدها و فروش‌ها (وضعیت، پیگیری)
- مدیریت ربات‌های فرعی (افزودن، حذف، فعال/غیرفعال)
- مدیریت کانال‌های اجباری (افزودن، حذف، تخصیص به ربات‌ها)
- گزارش‌های تفصیلی

### 🤖 ربات‌های فرعی
- سیستم مکمل برای اجرا تحت کنترل ربات اصلی
- API های تلگرام تلقائی (restrictChatMember, unrestrictChatMember)
- سیستم کانال‌های اجباری
- محدود کردن کاربران در کانال‌ها
- تتبع وضعیت کاربران

### 📢 کانال‌های اجباری
- تخصیص کانال‌ها به ربات‌های فرعی
- محدود کردن خودکار اعضا
- رفع محدودیت کاربران معتبر
- سیستم تأیید عضویت

### 🎨 طراحی
- دکمه‌های شیشه‌ای (Glassy)
- ایموجی‌های Premium روی دکمه‌ها و متن‌ها
- سه رنگ: آبی🔵 قرمز🔴 سبز🟢
- رابط‌کاربری جذاب

## 💬 استفاده

### برای کاربران

**خرید اعضا:**
```
/start → خرید اعضا → تعداد (مثل: 100)
→ منتظر تأیید مدیر
```

**فروش اعضا:**
```
/start → فروش اعضا → تعداد قیمت (مثل: 100 50)
→ سود خودکار: 10% = 500 تومان
→ کل: 5500 تومان
```

**تنظیمات:**
```
/start → تنظیمات
- 📱 شماره تلفن
- 💳 روش پرداخت (تتر/ترون/تومی)
- 🏦 آدرس کیف پول
```

### برای مدیریت (ادمین)

**اضافه کردن ربات فرعی:**
```
منوی مدیریت → ربات‌های فرعی → افزودن
→ توکن ربات را بفرستید
→ ربات اضافه می‌شود
```

**مدیریت کانال‌های اجباری:**
```
منوی مدیریت → کانال‌ها → افزودن
→ شناسه ربات (مثل: bot1)
→ شناسه کانال (مثل: -1001234567890)
→ کانال فعال می‌شود
```

**مدیریت وضعیت ربات‌ها:**
```
پنل مدیریت → ربات‌های فرعی
- 🔄 فعال/غیرفعال کردن
- 🗑️ حذف ربات
```

## 🆘 مشکل گیری

**مشکل:** ربات متصل نمی‌شود
```
حل:
1. setup.php را باز کنید
2. کلیک بر روی "🧪 تست اتصال"
3. توکن را بررسی کنید
4. اگر هنوز مشکل دارد، کد test.php را اجرا کنید
```

**مشکل:** Webhook کار نمی‌کند
```
حل:
- دامنه شما HTTPS باشد (HTTP کار نمی‌کند)
- آدرس درست وارد شده باشد (مثل: https://example.com/bot.php)
- از setup.php دوباره تلاش کنید
- پیام /start را به ربات بفرستید
```

**مشکل:** داده‌ها ذخیره نمی‌شوند
```
حل: پوشه data/ باید قابل نوشتن باشد
chmod 755 data/
```

**مشکل:** ربات فرعی کار نمی‌کند
```
حل:
1. توکن ربات فرعی درست است؟
2. شناسه ربات درست وارد شده؟
3. کانال اجباری درست تنظیم شده؟
4. ربات فرعی مدیر کانال است؟
```

**مشکل:** پنل مدیریت کار نمی‌کند
```
حل:
1. آدرس: https://yourdomain.com/admin.php
2. کد ورود: 8213021584
3. cookies روی مرورگر حذف کنید
```

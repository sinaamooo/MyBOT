# 🐕 ربات هاپی — نسخه PHP

بازنویسی کامل ربات تلگرامی «هاپی» از پایتون به **PHP**، در یک فایل واحد (`bot.php`)
با تمام قابلیت‌های نسخه اصلی به‌علاوهٔ قابلیت‌های جدید.

---

## ✨ چه چیزهایی اضافه شده

| قابلیت | توضیح |
|---|---|
| 🎯 **چالش دوز** | با نوشتن `چالش 500 میو` یک چالش باز می‌شود؛ هر کسی آن مقدار میو پوینت داشته باشد با **دکمهٔ سبز** وارد می‌شود و بازی دوز (XO) شروع می‌شود. |
| 🎨 **دکمه‌های رنگی واقعی** | با فیلد `style` از **Bot API 9.4**: 🔵 `primary` · 🟢 `success` · 🔴 `danger`. رنگ هر دسته از پنل قابل تغییر است. |
| ✨ **ایموجی پریمیوم** | هم داخل متن پیام‌ها (`<tg-emoji>`) و هم روی دکمه‌ها (`icon_custom_emoji_id`). |
| 🛠 **پنل `/panel`** | ویرایش کامل متن‌ها، رنگ دکمه‌ها، ایموجی پریمیوم و جایگزینی سراسری — بدون دست زدن به کد. |
| 💬 **Quote کردن متن‌ها** | همهٔ پاسخ‌ها روی پیام کاربر ریپلای می‌شوند و بدنهٔ پنل‌ها داخل `<blockquote>` تلگرام قرار می‌گیرد. |
| 📊 **آمار چالش** | کارنامهٔ برد/باخت/مساوی هر بازیکن در پروفایل و جدول `برترین چالش`. |

## 🛠 پنل مدیریت — `/panel`

فقط برای آیدی‌های داخل `ADMIN_IDS`. در پیوی یا گروه با `/panel` یا نوشتن `پنل` باز می‌شود.

```
🛠 پنل مدیریت ربات
├── 📝 ویرایش متن‌ها          دسته‌بندی‌شده، با نمایش متن فعلی و پیش‌فرض
├── 🎨 رنگ و ایموجی دکمه‌ها   رنگ رسمی تلگرام + ایموجی پریمیوم هر دسته
├── ✨ ایموجی پریمیوم         نگاشت ایموجی معمولی → پریمیوم در کل متن‌ها
├── 🔁 جایگزینی سراسری        هر عبارت در هر پیامی، حتی بدون کلید
├── 👀 پیش‌نمایش              نمونهٔ زندهٔ پیام و همهٔ رنگ دکمه‌ها
├── 🗂 پنل‌های دیگر           قرعه‌کشی · مارکت · دعوت دوستان
└── ♻️ بازگردانی کامل
```

### ویرایش متن

متن جدید را همان‌طور که می‌خواهید بفرستید — **بولد، ایتالیک، کد، اسپویلر، نقل‌قول و ایموجی پریمیوم همه حفظ می‌شوند** (از `entities` پیام خوانده و به HTML تبدیل می‌شوند).

متن‌هایی که جای‌گذار دارند (مثل `{name}` یا `{bet}`) در پنل نمایش داده می‌شوند و اگر آن‌ها را نگذارید هشدار می‌گیرید.

### جایگزینی سراسری

برای متن‌هایی که کلید جدا ندارند:

```
هاپ پوینت | میو پوینت
```

از این به بعد در **همهٔ** پیام‌های ربات جایگزین می‌شود. داخل `<code>` و تگ‌های HTML دست نمی‌خورد.

### رنگ دکمه‌ها

شش دستهٔ داخلی (`موفق`، `خطرناک`، `عادی`، `هشدار`، `ویژه`، `ساده`) هرکدام به یکی از سه رنگ رسمی تلگرام یا «بدون رنگ» نگاشت می‌شوند. تغییر رنگ یک دسته، فوراً روی همهٔ دکمه‌های آن دسته در کل ربات اعمال می‌شود.

### ایموجی پریمیوم

یک پیام حاوی ایموجی پریمیوم بفرستید؛ ربات `custom_emoji_id` را از `entities` می‌خواند و ذخیره می‌کند.

> ⚠️ **شرط تلگرام:** ایموجی پریمیوم فقط وقتی نمایش داده می‌شود که **مالک ربات اشتراک Telegram Premium داشته باشد** (یا ربات از Fragment یوزرنیم خریده باشد). اگر تلگرام آن را رد کند، ربات یک‌بار بدون ایموجی دوباره می‌فرستد و قابلیت را خودکار خاموش می‌کند تا پیام‌ها از دست نروند.

## 🎮 چالش دوز چطور کار می‌کند

```
چالش 500 میو        ← ساخت چالش با شرط ۵۰۰
چالش 10k میو        ← پشتیبانی از k / m
چالش ۲۰۰۰            ← ارقام فارسی
چالش               ← نمایش راهنما
برترین چالش         ← جدول برترین‌ها
```

پیامی که ربات می‌فرستد **دو دکمه** دارد:

| دکمه | کار |
|---|---|
| 🟢 **شرکت در چالش دوز (۵۰۰ میو)** | پیوستن به چالش (دکمهٔ سبز) |
| 🔵 **وضعیت چالش** | نمایش وضعیت لحظه‌ای + کارنامهٔ شخصی |
| 🔴 **لغو چالش** | فقط برای سازنده — پوینت برمی‌گردد |

**قوانین:**

- شرط از هر دو طرف کسر و در «گلدان» نگه داشته می‌شود.
- برنده `۲ × شرط + ۵٪ پاداش` می‌گیرد (`CHALLENGE_WIN_BONUS`).
- مساوی → پوینت هر دو کامل برمی‌گردد.
- اگر تا `۳ دقیقه` کسی نپیوندد → چالش منقضی و پوینت سازنده برمی‌گردد.
- اگر بازیکنی تا `۹۰ ثانیه` نوبتش را بازی نکند → حریف برنده می‌شود.
- هر کاربر همزمان فقط یک چالش فعال دارد.

## 🚀 نصب و اجرا

### پیش‌نیاز

- PHP **8.0** یا بالاتر
- ربات باید روی **Bot API 9.4+** کار کند (رنگ دکمه و ایموجی پریمیوم از این نسخه اضافه شده)
- افزونه‌های `pdo_sqlite`، `curl`، `mbstring`

```bash
php -m | grep -E 'pdo_sqlite|curl|mbstring'
```

### تنظیمات

بالای `bot.php` این مقادیر را ویرایش کنید:

```php
define('BOT_TOKEN',    '123456:ABC-DEF...');   // توکن از @BotFather
define('BOT_USERNAME', 'my_happy_bot');        // بدون @
define('ADMIN_IDS',    [123456789]);           // آیدی عددی ادمین‌ها
```

> ⚠️ توکن را در مخزن عمومی کامیت نکنید.

### اجرا — حالت پولینگ (ساده‌ترین)

```bash
php bot.php
```

اجرای دائمی با systemd:

```ini
# /etc/systemd/system/happybot.service
[Unit]
Description=Happy Dog Telegram Bot
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/happybot
ExecStart=/usr/bin/php /opt/happybot/bot.php
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now happybot
```

### اجرا — حالت وبهوک (روی هاست اشتراکی)

```bash
php bot.php --set-webhook=https://example.com/bot.php
```

فایل را در ریشهٔ دامنه بگذارید. برای کارهای زمان‌بندی‌شده یک کران هر دقیقه اضافه کنید:

```cron
* * * * * /usr/bin/php /path/to/bot.php --cron >/dev/null 2>&1
```

### سایر فرمان‌ها

```bash
php bot.php --help             # راهنما
php bot.php --init-db          # فقط ساخت دیتابیس
php bot.php --delete-webhook   # حذف وبهوک
php bot.php --cron             # اجرای یک‌بارهٔ کارهای دوره‌ای
```

## 🗂 ساختار داده

دیتابیس `happy_bot.db` (SQLite با WAL) شامل **۶۰ جدول** است و در اولین اجرا خودکار ساخته می‌شود.
مهاجرت خودکار (`migrateDb`) ستون‌های جاافتاده را به دیتابیس‌های قدیمی اضافه می‌کند.

جدول‌های کلیدی: `users`، `groups`، `dogs`، `hooks`، `bank`، `factories`،
`challenges`، `challenge_stats`، `mayor*`، `leader*`، `user_market*`، `lotteries*`.

> چون PHP بین درخواست‌ها حافظه ندارد، وضعیت مکالمه‌ها (که در نسخهٔ پایتون در
> `context.user_data` بود) در جدول `user_states` نگهداری می‌شود و پس از یک ساعت
> بی‌استفاده ماندن خودکار پاک می‌شود.

## ⚙️ تنظیمات قابل تغییر

همهٔ اعداد بازی به‌صورت ثابت (`const`) بالای فایل تعریف شده‌اند:

```php
const HOP_COOLDOWN          = 300;      // کولداون هاپ
const CHALLENGE_MIN_BET     = 100;      // حداقل شرط چالش
const CHALLENGE_JOIN_WINDOW = 180;      // مهلت پیوستن
const CHALLENGE_TURN_TIME   = 90;       // مهلت هر نوبت
const CHALLENGE_WIN_BONUS   = 0.05;     // پاداش برنده
const PANEL_RETURN_DELAY    = 2;        // مکث بازگشت به پنل (۰ = بدون مکث)
const FORCE_JOIN_ENABLED    = false;    // جوین اجباری
```

> در حالت وبهوک، `PANEL_RETURN_DELAY` را روی `0` بگذارید تا درخواست بلاک نشود.

## ✅ کیفیت

- بدون خطای نحوی (`php -l`)
- **۳۳۴ تست** پوششی روی همهٔ ماژول‌ها (اقتصاد، چالش، سیاست، ادمین، پنل، امنیت)
- **۴۰۰۰ آپدیت تصادفی** فاز‌شده بدون هیچ هشدار یا خطا
- بررسی یکپارچگی: موجودی منفی، سطح نامعتبر، چالش ناقص، خزانهٔ منفی — همه صفر
- همهٔ تراکنش‌های مالی داخل `transaction` با قفل خوش‌بینانه (جلوگیری از دبل‌اسپند روی دکمه‌ها)
- خروجی `HTML` با escape کامل (`htmlspecialchars`) — مقاوم در برابر تزریق مارک‌آپ
- همهٔ کوئری‌ها با `prepared statement` — مقاوم در برابر SQL Injection

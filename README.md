# ربات ساخت پک ایموجی پریمیوم (PHP)

کاربر ایموجی‌های پریمیوم می‌فرسته و ربات از اون‌ها یک **پک ایموجی** (custom emoji set) می‌سازه و لینکش رو می‌ده.

## روند کار ربات
1. کاربر `/start` می‌زنه → ربات **اسم پک** رو می‌پرسه.
2. کاربر ایموجی‌های پریمیوم رو می‌فرسته (در یک یا چند پیام، حداکثر ۲۰۰ ایموجی). ایموجی‌های تکراری حذف می‌شن.
3. کاربر دکمه **«✅ ساخت پک»** رو می‌زنه (یا `/done`).
4. ربات پک رو به اسم خود کاربر می‌سازه و لینک `https://t.me/addemoji/...` رو همراه دکمه «➕ افزودن پک» می‌فرسته.

دستورها: `/start` ، `/done` ، `/cancel` ، `/help`

## فایل‌ها
| فایل | کار |
|---|---|
| `bot.php` | منطق ربات (webhook و polling) |
| `lib.php` | اتصال به API تلگرام و ذخیره وضعیت کاربرها |
| `set_webhook.php` | وصل کردن ربات به تلگرام (webhook) |
| `config.example.php` | نمونه تنظیمات؛ از روش `config.php` بسازید |
| `data/` | وضعیت کاربرها و `error.log` |

## نصب روی هاست (webhook)
پیش‌نیاز: PHP 7.4 یا بالاتر با افزونه `curl` و دامنه با **HTTPS**. هاست باید به `api.telegram.org` دسترسی داشته باشه (هاست خارج از ایران).

1. همه فایل‌ها رو داخل یک پوشه روی هاست آپلود کنید.
2. `config.example.php` رو کپی کنید و اسمش رو `config.php` بذارید. بعد این‌ها رو پر کنید:
   - `bot_token`: توکن ربات از @BotFather
   - `webhook_url`: آدرس کامل `bot.php`، مثلاً `https://yourdomain.com/emoji-bot/bot.php`
3. پوشه `data` باید قابل نوشتن باشه (دسترسی 755 یا 775).
4. یک بار `https://yourdomain.com/emoji-bot/set_webhook.php` رو در مرورگر باز کنید. باید پیام `✅ Webhook set` ببینید.
5. در تلگرام به ربات `/start` بدید.

> ⚠️ webhook رو حتماً با `set_webhook.php` تنظیم کنید. ربات فقط درخواست‌هایی رو قبول می‌کنه که کد امنیتی (secret token) مخصوص خودش رو داشته باشن.

## اجرا روی سرور/VPS (بدون دامنه، polling)
```bash
cp config.example.php config.php   # توکن را داخلش بگذارید
php bot.php
```
یا بدون `config.php`: `BOT_TOKEN=xxxx php bot.php`

## نکات
- توکن رو داخل گیت نذارید؛ `config.php` در `.gitignore` هست.
- اگر ایموجی‌ای با `file_id` قبول نشه، ربات فایلش رو دانلود می‌کنه و دوباره آپلود می‌کنه. اگر باز هم نشد، ازش رد می‌شه و در پیام آخر تعدادشون رو می‌گه.
- خطاها در `data/error.log` ذخیره می‌شن.

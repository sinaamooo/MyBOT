# 🤖 NIKTO CRYPTO BOT

ربات تلگرامی PHP برای انتشار خودکار کارت‌های گرافیکی بازار رمزارز در کانال.

سه کارت آماده دارد و همه‌چیز از داخل خود تلگرام مدیریت می‌شود — بدون نیاز به ویرایش کد:

| کارت | محتوا | منبع داده |
|---|---|---|
| 📈 **نوسان ارزها** | قیمت، درصد و مقدار تغییر ۲۴ ساعته، نمودار کوچک ۲۴ ساعته برای تا ۹ ارز | Binance → CoinGecko |
| 😨 **ترس و طمع** | سنجه‌ی افقی قرمز تا سبز، مقدار دیروز / ۷ روز / ۱ ماه پیش، نمودار ۳۰ روزه | alternative.me |
| 📅 **تقویم اقتصادی** | جدول رویدادهای روز با زمان، ارز، پرچم، اهمیت، مقدار قبلی و پیش‌بینی — **ترجمه‌شده به فارسی** | ForexFactory → TradingView |

## ✨ ویژگی‌ها

- **طراحی روشن و خوانا** — پس‌زمینه‌ی سفید با تأکید سبز و قرمز و حاشیه‌های مشکی؛ در حالت روشن و تیره‌ی تلگرام یکسان دیده می‌شود.
- **لوگوی اختصاصی هر ارز** روی کارت قیمت‌ها (۴۱ لوگو همراه پروژه، بدون نیاز به اینترنت).
- **پنل کامل فارسی داخل تلگرام** — کانال مقصد، ساعت ارسال، روزهای هفته، تم رنگی، کپشن و ارزها؛ همه با دکمه.
- **زمان‌بندی دقیقه‌ای** — برای هر کارت چند ساعت مختلف در روز، با انتخاب روزهای هفته و منطقه‌ی زمانی دلخواه (پیش‌فرض `Asia/Tehran`).
- **تاریخ شمسی** روی کارت‌ها و در پنل.
- **متن فارسی واقعی روی تصویر** — موتور اختصاصی شکل‌دهی حروف (اتصال حروف، لام‌الف، نیم‌فاصله) و چینش دوسویه (Bidi) که اعداد و متن لاتین را در جای درست نگه می‌دارد.
- **۴ تم روشن** — «روشن» (سفید/سبز/قرمز، پیش‌فرض)، برفی، نعنایی و کاغذی.
- **ایموجی پریمیوم** در کپشن — چه خودتان ایموجی پریمیوم بفرستید، چه شناسه‌ی عددی آن را داخل کروشه بنویسید (`[5368324170671202286]`).
- **پرچم‌های برداری** ۲۵ کشور — بدون نیاز به فایل تصویر یا فونت ایموجی.
- **بدون وابستگی خارجی** — نه Composer، نه کتابخانه‌ی جانبی. فقط PHP + GD + SQLite.
- **جلوگیری از ارسال تکراری** و **جبران تأخیر** اگر سرور چند دقیقه خواب بود.
- **تست خودکار آفلاین** با ۴۹ بررسی (`tools/selftest.php`) و بازرسی چیدمان (`tools/layout-check.php`).

## ⚡️ نصب

### پیش‌نیازها

```bash
# دبیان / اوبونتو
sudo apt update
sudo apt install -y php-cli php-gd php-curl php-sqlite3 php-mbstring
```

PHP نسخه‌ی **۸.۱ یا بالاتر** لازم است و افزونه‌ی GD باید با پشتیبانی FreeType ساخته شده باشد.

### گام‌های نصب

```bash
git clone https://github.com/sinaamooo/MyBOT.git
cd MyBOT

# ثبت توکن (فقط یک‌بار) — فایل config.local.php ساخته می‌شود
php tools/install.php --token=123456789:AAH...

# بررسی سلامت نصب
php tools/doctor.php

# اجرا
php bot.php          # ربات و پنل
php scheduler.php    # زمان‌بند (در ترمینال دوم)
```

تنظیمات عمومی (شناسه‌ی مدیر `6595849261`، دامنه‌ی وب‌هوک، منطقه‌ی زمانی) از قبل در
`config.php` آماده است؛ فقط توکن باید یک‌بار ثبت شود.

> 🔐 **چرا توکن در مخزن نیست؟** هر کسی که به مخزن دسترسی داشته باشد با آن توکن
> کنترل کامل ربات را می‌گیرد. به همین دلیل توکن در `config.local.php` ذخیره می‌شود
> که در `.gitignore` است. راه دیگر: `BOT_TOKEN=123456789:AAH... php bot.php`
>
> اگر توکن جایی لو رفت، در @BotFather دستور `/revoke` را بزنید و دوباره
> `php tools/install.php --token=... --force` را اجرا کنید.

## 🚀 راه‌اندازی در ۴ قدم

1. ربات را در کانال مقصد **ادمین** کنید (با دسترسی ارسال پیام).
2. در چت خصوصی ربات `/start` بزنید ← **📡 کانال‌ها ← ➕ افزودن کانال** ← یک پست از کانال را فوروارد کنید (یا `@username` کانال را بفرستید).
3. وارد هر کارت شوید ← **⏰ زمان‌بندی ← ➕ افزودن زمان** و ساعت‌ها را بفرستید، مثلاً:
   ```
   09:00, 15:30, 21:45
   ```
   در صورت نیاز با **📆 روزها** فقط روزهای خاصی از هفته را انتخاب کنید.
4. همان کارت را با **✅ روشن کن** فعال کنید. تمام.

با **👁 پیش‌نمایش** کارت فقط برای خودتان ساخته و ارسال می‌شود و با **🚀 ارسال فوری** بلافاصله به کانال‌ها می‌رود.

## 💎 ایموجی پریمیوم در کپشن

کپشن هر کارت از داخل پنل ویرایش می‌شود: **کارت → کپشن**. قالب‌بندی خود تلگرام (بولد، ایتالیک، زیرخط، نقل‌قول، کد، لینک) حفظ می‌شود و برای ایموجی پریمیوم دو راه وجود دارد:

**۱) مستقیم** — اگر حساب خودتان پریمیوم است، کافی است ایموجی پریمیوم را همان‌جا داخل متن کپشن بفرستید. تلگرام آن را به‌صورت `custom_emoji` می‌فرستد و ربات عیناً در کانال بازتولیدش می‌کند.

**۲) با شناسه‌ی عددی** — شناسه‌ی ایموجی را داخل کروشه بنویسید:

```
[5368324170671202286] گزارش بازار امروز
```

هنگام ارسال به این تبدیل می‌شود:

```html
<tg-emoji emoji-id="5368324170671202286">😎</tg-emoji> گزارش بازار امروز
```

اگر **درست قبل از کروشه** یک ایموجی معمولی بگذارید، همان ایموجی به‌عنوان جایگزین کاربران بدون پریمیوم استفاده می‌شود و از متن حذف می‌گردد:

```
🔥[5368324170671202286]  →  <tg-emoji emoji-id="5368324170671202286">🔥</tg-emoji>
```

نکته‌ها:

- فقط عددهای **۸ رقم به بالا** داخل کروشه تبدیل می‌شوند؛ بنابراین چیزی مثل `[1404]` دست‌نخورده می‌ماند.
- شناسه را می‌توانید از ربات‌هایی مثل `@idstickerbot` یا با فوروارد پیام حاوی ایموجی پریمیوم به یک ربات شناسه‌خوان بگیرید.
- حقِ استفاده از ایموجی پریمیوم مالِ **توکن ربات** است، نه حساب ادمین. اگر ربات این اجازه را نداشته باشد، پست **از دست نمی‌رود**: ربات یک بار دیگر همان کارت را با ایموجی جایگزین می‌فرستد و در گزارش می‌نویسد «بدون ایموجی پریمیوم ارسال شد».

## 🔧 اجرای دائمی (systemd)

```bash
sudo cp deploy/nikto-bot.service deploy/nikto-scheduler.service /etc/systemd/system/
sudo nano /etc/systemd/system/nikto-bot.service     # مسیر و کاربر را اصلاح کنید
sudo systemctl daemon-reload
sudo systemctl enable --now nikto-bot nikto-scheduler
sudo systemctl status nikto-bot
```

اگر systemd ندارید، زمان‌بند را با cron اجرا کنید:

```cron
* * * * * /usr/bin/php /path/to/MyBOT/scheduler.php --once >> /dev/null 2>&1
```

### حالت وب‌هوک (به‌جای `bot.php`)

آدرس وب‌هوک در `config.php` تنظیم شده است:

```
https://nikto.s14.telviprobot.top/webhook.php
```

```bash
php tools/webhook-set.php            # ثبت همین آدرس روی تلگرام
php tools/webhook-set.php --info     # وضعیت فعلی
php tools/webhook-set.php --delete   # حذف وب‌هوک و برگشت به bot.php
```

پیش‌نیازها:

1. دامنه باید **SSL معتبر** داشته باشد (تلگرام فقط `https` می‌پذیرد).
2. ریشه‌ی دامنه به پوشه‌ی پروژه اشاره کند؛ نمونه‌ی پیکربندی در `deploy/nginx.conf.sample`
   و برای هاست اشتراکی `deploy/.htaccess.sample`.
   با این تنظیم، هم `/` و هم `/webhook.php` آپدیت‌ها را می‌گیرند.
3. مسیرهای `config.php`، `data/` و `storage/` نباید از بیرون قابل دسترسی باشند —
   هر دو فایل نمونه این کار را انجام می‌دهند.
4. در حالت وب‌هوک `bot.php` لازم نیست، اما **`scheduler.php` باید همچنان اجرا شود**.

## 📦 نسخه‌ی «دو فایلی» (هاست اشتراکی با چند ربات)

اگر روی هاست چند ربات مختلف دارید و نمی‌خواهید پوشه‌ی کامل پروژه را آپلود کنید،
کل پروژه در **دو فایل** فشرده می‌شود:

```bash
php tools/build.php --with-secrets          # خروجی در build/
php tools/build.php --name=mybot --out=/tmp # نام و مسیر دلخواه
```

خروجی:

| فایل | نقش |
|---|---|
| `nikto-bot.php` | همه‌ی کدها + فونت فارسی + ۴۱ لوگوی ارز؛ وب‌هوک، پنل و خط فرمان |
| `nikto-cron.php` | زمان‌بند؛ کرون سرور، اجرای دائمی یا کرون اینترنتی |

فقط همین دو فایل را آپلود کنید. بار اول که اجرا شوند، فونت‌ها و لوگوها را در پوشه‌ی
`nikto-<شناسه‌ی ربات>-data/` کنار خودشان باز می‌کنند (برای هر ربات جدا، پس چند ربات
روی یک هاست با هم قاطی نمی‌شوند) و دسترسی وب به آن پوشه هم بسته می‌شود.

```bash
php nikto-bot.php doctor        # بررسی سلامت
php nikto-bot.php webhook       # ثبت وب‌هوک (آدرس از بالای همان فایل خوانده می‌شود)
php nikto-bot.php               # یا حالت پولینگ، بدون وب‌هوک
php nikto-bot.php send prices   # ارسال فوری یک کارت
php nikto-cron.php              # یک تیک زمان‌بند (برای کرون هر دقیقه)
php nikto-cron.php --loop       # اجرای دائمی زمان‌بند
```

اگر هاست شما کرون خط فرمان ندارد، هر دقیقه این آدرس را صدا بزنید:

```
https://your-domain/nikto-cron.php?key=<webhook_secret>
```

توکن و شناسه‌ی مدیر در بالای `nikto-bot.php` قابل ویرایش هستند.

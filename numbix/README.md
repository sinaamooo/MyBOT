# نامبیکس | Numbix

فروشگاه و پنل حرفه‌ای خدمات شبکه‌های اجتماعی (SMM) با PHP خالص — بدون نیاز به Composer یا Node، قابل اجرا روی هر هاست اشتراکی (cPanel / DirectAdmin / Plesk).

## امکانات

**ظاهر کهکشانی زنده (Cosmos)**
- پس‌زمینه کهکشان متحرک: ستاره‌های چشمک‌زن با عمق سه‌بعدی، شهاب‌سنگ، سحابی‌های در حال حرکت و افکت نور زیر ماوس
- سیاره درخشان با حلقه و اتمسفر، آیکون پلتفرم‌ها در مدارهای سه‌بعدی (جلو/پشت سیاره)، کارت‌های شیشه‌ای با حاشیه نئونی متحرک و چرخش سه‌بعدی
- مسیر پرتاب، رادار زنده سفارش‌ها، ترمینال تایپ‌شونده API، کرم‌چاله، افق سیاره در فوتر و صفحه ۴۰۴ «گم‌شده در فضا»
- پنل‌های مدیریت و کاربری فضایی با نمودارهای نئونی؛ تم «سپیده» روشن هم قابل انتخاب است
- همه انیمیشن‌ها بهینه هستند و برای کاربرانی که «کاهش حرکت» را فعال کرده‌اند خاموش می‌شوند

**سایت**
- طراحی کاملاً راست‌چین، فونت وزیرمتن (لوکال، بدون CDN)
- صفحه اصلی با هدر متحرک، جستجوی زنده، دسته‌بندی‌ها، محبوب‌ترین خدمات، آمار زنده، سوالات متداول و وبلاگ
- لیست خدمات با فیلتر دسته، بازه قیمت، نوع خدمت، فقط موجود/تخفیف‌دار و مرتب‌سازی
- صفحه هر سرویس با محاسبه‌گر قیمت لحظه‌ای، سبد خرید چندتایی و کد تخفیف
- ورود/ثبت‌نام، بازیابی رمز، ورود با گوگل و تلگرام (اختیاری)، منوی پایین مخصوص موبایل

**پنل کاربری**
- داشبورد با نمودار، ثبت سفارش سریع، پیگیری لحظه‌ای سفارش‌ها (تعداد شروع / باقی‌مانده)
- کیف پول: شارژ آنلاین زرین‌پال، کارت‌به‌کارت با آپلود رسید، تاریخچه تراکنش‌ها
- تیکت پشتیبانی با پیوست، علاقه‌مندی‌ها، اعلان‌ها، پروفایل
- **وب‌سرویس API** سازگار با استاندارد SMM API v2 برای همکاران و ربات‌ها

**پنل مدیریت**
- داشبورد با نمودار فروش، آخرین سفارش‌ها، محبوب‌ترین خدمات، وضعیت سیستم و جستجوی سراسری (Ctrl+K)
- مدیریت محصولات، دسته‌بندی‌ها (با رنگ و آیکون برند)، **افزایش موجودی** با سابقه و هشدار موجودی کم
- سفارش‌ها: فیلتر کامل، تغییر وضعیت گروهی، خروجی Excel، ثبت سفارش دستی برای کاربر
- کاربران: شارژ/کسر کیف پول، مسدودسازی، ورود به حساب کاربر
- تیکت‌ها با پاسخ‌های آماده، پرداخت‌ها و تایید فیش، کدهای تخفیف، بنرها با آمار کلیک، وبلاگ/صفحات/سوالات متداول
- گزارش فروش و سود، تنظیمات کامل سایت از داخل پنل

**اتوماسیون (خودکار)**
- اتصال به پنل‌های تامین‌کننده (SMM API v2): ورود گروهی سرویس‌ها با درصد سود دلخواه
- ارسال خودکار سفارش به API بلافاصله بعد از پرداخت + تلاش مجدد در صورت خطا
- همگام‌سازی خودکار وضعیت سفارش‌ها؛ در صورت لغو یا انجام ناقص، **بازگشت خودکار وجه** به کیف پول
- کسر و بازگرداندن خودکار موجودی، ناموجود شدن خودکار محصول، هشدار موجودی کم
- لغو خودکار سفارش‌های پرداخت‌نشده، بستن خودکار تیکت‌های قدیمی
- اطلاع‌رسانی به مدیر در تلگرام (سفارش جدید، تیکت، پرداخت، موجودی کم)
- اگر هاست کرون‌جاب ندارد، اتوماسیون با بازدیدهای سایت هم اجرا می‌شود

## پیش‌نیازها
- PHP 8.0 یا بالاتر با افزونه‌های `pdo_mysql`، `mbstring`، `curl`، `json`، `fileinfo`
- MySQL 5.7+ یا MariaDB 10.3+
- ترجیحاً Apache یا LiteSpeed با `mod_rewrite` (بدون آن هم با آدرس‌های `index.php?r=` کار می‌کند)

## نصب (کمتر از ۲ دقیقه)
1. محتوای پوشه `numbix` را در `public_html` (یا هر پوشه‌ای) آپلود و از حالت فشرده خارج کنید.
2. از پنل هاست یک دیتابیس MySQL و یک کاربر بسازید و کاربر را با همه دسترسی‌ها به دیتابیس متصل کنید.
3. آدرس `https://your-site.com/install` (برای شما: `https://nikto.s14.telviprobot.top/install`) را باز کنید، اطلاعات دیتابیس و مدیر را وارد کنید و «شروع نصب» را بزنید.
4. پوشه `install` را از هاست حذف کنید.
5. در پنل هاست یک Cron Job برای هر ۵ دقیقه بسازید:
   ```
   */5 * * * * php /home/USERNAME/public_html/cron.php >/dev/null 2>&1
   ```
   (آدرس وب‌کرون هم در «تنظیمات سایت ← اتوماسیون» نمایش داده می‌شود.)
6. با ایمیل و رمزی که در نصب وارد کردید وارد شوید؛ پنل مدیریت در `/admin` است.

> اگر نصب‌کننده نتوانست فایل `config.php` را بسازد، محتوای آن را نمایش می‌دهد تا دستی بسازید. نمونه آن در `config.sample.php` است.

## تنظیمات مهم بعد از نصب
- **درگاه زرین‌پال:** تنظیمات سایت ← پرداخت ← مرچنت کد. تا قبل از آن، «درگاه آزمایشی» فقط برای مدیران فعال است تا کل فرایند خرید را تست کنید.
- **کارت به کارت:** شماره کارت را وارد کنید تا فرم ثبت فیش برای کاربران فعال شود.
- **اتصال API خودکار:** منوی «اتصال API خودکار» ← افزودن ارائه‌دهنده ← «ورود سرویس‌ها».
- **اطلاع‌رسانی تلگرام:** تنظیمات ← اتوماسیون ← توکن ربات و Chat ID مدیر.
- **نماد اعتماد:** تنظیمات ← تماس و فوتر ← کد اینماد.

## Nginx
اگر وب‌سرور شما Nginx است، این قوانین را اضافه کنید:
```nginx
location / { try_files $uri $uri/ /index.php?$query_string; }
location ~ ^/(app|storage)/ { deny all; }
location ~ ^/uploads/.*\.php$ { deny all; }
location ~ ^/(config|config\.sample|cron)\.php$ { deny all; }
```

## ساختار پروژه
```
index.php          ورودی اصلی (Front Controller)
cron.php           اجرای اتوماسیون از طریق Cron
install/           نصب‌کننده خودکار + اسکیمای دیتابیس
app/core/          هسته: روتر، دیتابیس، احراز هویت، توابع کمکی، تقویم شمسی
app/services/      منطق کسب‌وکار: سفارش، کیف پول، API تامین‌کننده، زرین‌پال، اتوماسیون
app/controllers/   کنترلرهای سایت، پنل کاربر و مدیریت
app/views/         قالب‌ها
assets/            CSS، JS، فونت و Chart.js
uploads/           فایل‌های آپلودی (اجرای PHP در آن مسدود است)
storage/           لاگ‌ها
```

## امنیت
- رمزها با `password_hash`، همه کوئری‌ها Prepared Statement، توکن CSRF روی تمام فرم‌ها
- محدودیت تلاش ناموفق ورود، کوکی‌های HttpOnly / SameSite، جلوگیری از Open Redirect
- اعتبارسنجی نوع واقعی فایل‌های آپلودی و غیرفعال بودن اجرای اسکریپت در `uploads`
- پیشنهاد می‌شود SSL (https) روی دامنه فعال باشد.

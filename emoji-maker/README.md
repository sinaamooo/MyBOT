# سازنده‌ی ایموجی پریمیوم تلگرام (PHP)

ربات و پنل کامل ساخت **ایموجی سفارشی متحرک تلگرام** با خروجی واقعی WEBM (ویدیویی، VP9 با شفافیت)،
TGS (برداری Lottie) و PNG، همراه با **قالب‌های آماده‌ی پریمیوم** که هر خریدار لوگو، متن و رنگ برند
خودش را روی آن‌ها می‌گذارد، و انتشار مستقیم پک ایموجی از طریق Bot API رسمی.

هسته‌ی پروژه کاملاً با PHP نوشته شده (بدون کتابخانه‌ی خارجی): شکل‌دهی درست متن فارسی و انگلیسی،
رندر و انیمیشن، ساخت TGS، پخش‌کننده‌ی Lottie سازگار با موتور تلگرام، اعتبارسنجی، صف کار، ربات و
پنل. تنها ابزار بیرونی، FFmpeg برای فشرده‌سازی ویدیوی WEBM است.

## امکانات

* **ربات فارسی** با منوی کامل و مراحل شیشه‌ای: ساخت از متن، عکس/لوگو یا هر دو؛ فونت، رنگ، دورخط،
  سایه، درخشش، عمق سه‌بعدی، قاب و پس‌زمینه؛ انتخاب انیمیشن؛ پیش‌نمایش؛ دانلود؛ انتشار پک.
* **موتور انیمیشن** با ۲۱ افکت (Pulse، Spin، Glow، Shake، Fade، Rise، Slide، Typewriter، Bounce، Flash،
  Color Shift، Arrow، Chart، Orbit، Pop، Swing، Float، Heartbeat، Jelly، Flip 3D، Tilt 3D) و ترکیب آن‌ها،
  با پارامترهای مدت، سرعت، شدت، جهت، تأخیر، ترتیب، رنگ، تکرار و حلقه‌ی بی‌درز.
* **پک چندتایی** ۱، ۵، ۱۰، ۲۰، ۵۰، ۱۰۰ یا تعداد دلخواه (تا سقف مدیر) با چند حالت تنوع، بدون خروجی
  تکراری، پیش‌نمایش شبکه‌ای و انتخاب موارد.
* **قالب‌های آماده‌ی پریمیوم:** ۸۴ ایموجی متحرک حرفه‌ای (سه بسته) که لوگو و متن برند اصلی‌شان حذف
  شده؛ کاربر لوگو یا متن خودش را می‌گذارد و رنگ برندش را انتخاب می‌کند؛ حرکت‌ها دقیقاً همان می‌ماند و
  رنگ‌های حساس (صورت، کاراکترها، طلا...) دست نمی‌خورند. مدیر می‌تواند بسته‌ی جدید وارد کند.
* **خروجی‌های معتبر:** هر فایل با قوانین رسمی تلگرام سنجیده می‌شود (ابعاد، کدک، مدت، فریم، حجم،
  ویژگی‌های ممنوع) و گزارش خوانا دارد. همه‌چیز در ZIP با فهرست تحویل داده می‌شود.
* **انتشار پک ایموجی** با `createNewStickerSet` / `addStickerToSet` (تا ۲۰۰ ایموجی) و ارسال لینک افزودن.
* **پنل مدیریت فارسی و واکنش‌گرا:** داشبورد، کاربران، پروژه‌ها و خروجی‌ها، صف کارها، افکت‌ها،
  قالب‌ها، فونت‌ها، تنظیمات امن، لاگ‌ها، گزارش تغییرات، وضعیت سیستم، مدیران.
* **صف کار** مبتنی بر دیتابیس با پیشرفت زنده، لغو، تلاش مجدد، محدودیت هم‌زمانی و پاک‌سازی خودکار؛
  اجرا با Cron (هاست اشتراکی) یا systemd/Supervisor (سرور).
* **امنیت:** توکن بیرون از سورس و رمزنگاری‌شده، اعتبارسنجی وبهوک، فایل‌های خصوصی بیرون از وب، لینک
  دانلود امضاشده، CSRF و نقش‌ها در پنل، محدودیت نرخ، لاگ‌های پاک‌سازی‌شده. جزئیات: `docs/SECURITY.md`.

## پیش‌نیازها و صادقانه: چه چیزی کجا کار می‌کند

| بخش | هاست اشتراکی (cPanel) | VPS / aaPanel |
|---|---|---|
| ربات، پنل، دیتابیس، صف | بله (PHP 8.1+، MySQL/MariaDB) | بله |
| خروجی TGS و PNG | بله (کاملاً PHP) | بله |
| خروجی WEBM و پیش‌نمایش MP4 | فقط اگر هاست FFmpeg با libvpx-vp9 و اجازه‌ی `proc_open` داشته باشد (اغلب ندارد) | بله (`apt install ffmpeg`) |
| پیش‌نمایش متحرک بدون FFmpeg | بله (GIF با PHP) | بله |
| اجرای کارها | Cron هر دقیقه از رابط cPanel (بدون SSH) | سرویس systemd/Supervisor (دائمی، سریع‌تر) |
| پک‌های بزرگ (۵۰ تا ۱۰۰ WEBM) | ممکن ولی کند و محدود به سهم CPU هاست | توصیه‌شده |
| وبهوک | نیاز به HTTPS معتبر (AutoSSL) | نیاز به HTTPS (Let's Encrypt) |

افزونه‌های PHP: `curl`، `gd`، `json`، `mbstring`، `pdo_mysql`، `zlib`؛ توصیه‌شده: `zip`، `sodium`، `fileinfo`.

## دستورهای مهم

```bash
php bin/install.php                 # نصب (بررسی پیش‌نیازها، .env، دیتابیس، مدیر، وبهوک)
php bin/doctor.php                  # گزارش سلامت محیط
php bin/worker.php --daemon         # کارگر دائمی (سرور)
php bin/cron.php                    # برای Cron هر دقیقه (هاست اشتراکی)
php bin/set-webhook.php             # ثبت/بررسی وبهوک
php bin/create-admin.php            # ساخت مدیر پنل
php bin/templates.php list          # قالب‌های آماده
php bin/validate.php file.webm      # اعتبارسنجی یک فایل با قوانین تلگرام
php tests/run.php                   # اجرای تست‌ها
php bin/build-zip.php               # ساخت بسته‌ی انتشار (بدون اطلاعات محرمانه)
```

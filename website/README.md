# سایت معرفی نامبیکس (Numbix) برای اینماد

سایت ایستا (فقط HTML و CSS)، راست‌به‌چپ و بدون وابستگی به سرویس خارجی. فونت وزیرمتن داخل خود سایت است و از گوگل بارگیری نمی‌شود.

```
website/
├── fill.py          ← جای‌گذاری خودکار اطلاعات واقعی
├── README.md
└── public/          ← فقط محتوای این پوشه (یا dist/) روی هاست می‌رود
    ├── index.html       صفحه‌ی اصلی و معرفی کسب‌وکار (+ جای کد تأیید و نماد اینماد)
    ├── services.html    خدمات و قیمت‌ها، نحوه‌ی خرید، پرسش‌های پرتکرار
    ├── about.html       درباره‌ی ما
    ├── contact.html     تماس با ما (موبایل، ایمیل، نشانی، کد پستی، ساعات کاری)
    ├── terms.html       قوانین و مقررات (+ شرایط بازگشت وجه)
    ├── privacy.html     حریم خصوصی
    ├── 404.html
    ├── robots.txt, sitemap.xml
    └── assets/ (css, fonts, img)
```

## ۱. پر کردن اطلاعات

همه‌ی جاهای خالی با `{{...}}` مشخص شده‌اند:

| کلید | چه چیزی بنویسید |
|---|---|
| `DOMAIN` | دامنه، مثل `numbix.ir` |
| `BOT_USERNAME` | نام کاربری ربات بدون @ |
| `OWNER_NAME` | نام صاحب کسب‌وکار (همان متقاضی اینماد) |
| `MOBILE` / `MOBILE_TEL` | موبایل برای نمایش / همان شماره برای لینک `tel:` (فقط رقم انگلیسی) |
| `EMAIL` | ایمیل |
| `ADDRESS` | نشانی کامل، دقیقاً مطابق نشانی ثبت‌شده در اینماد |
| `POSTAL_CODE` | کد پستی |
| `HOURS` | ساعات پاسخ‌گویی |
| `SERVICES_LINE` | یک جمله درباره‌ی خدمات (بدون نقطه‌ی پایانی) |
| `SERVICE_1..4` / `PRICE_1..4` | نام خدمت / قیمت به تومان |

**روش خودکار (پیشنهادی):** مقادیر `INFO` را در `fill.py` پر کنید و اجرا کنید:

```bash
python3 fill.py
```

خروجی در `dist/` ساخته می‌شود؛ `MOBILE_TEL` خودکار از `MOBILE` ساخته می‌شود و اعداد به فارسی و قیمت‌ها با جداکننده‌ی هزارگان نوشته می‌شوند. اگر چیزی خالی مانده باشد، اسمش را چاپ می‌کند.

**روش دستی:** در VS Code یا Notepad++ با «Replace in Files» هر `{{کلید}}` را در پوشه‌ی `public/` جایگزین کنید. در پایان دنبال `{{` بگردید؛ نباید چیزی پیدا شود.

## ۲. آپلود روی aaPanel

1. در DNS دامنه، رکورد A برای `numbix.ir` و `www.numbix.ir` را روی IP سرور بگذارید.
2. در aaPanel: **Website ← Add site**، دامنه (با و بدون www) را وارد کنید، PHP را روی **Static** بگذارید. ریشه‌ی سایت معمولاً `/www/wwwroot/دامنه` است.
3. فایل‌های پیش‌فرض `index.html` و `404.html` که aaPanel ساخته را پاک کنید (به `.user.ini` دست نزنید).
4. **محتوای** پوشه‌ی `dist/` (یا `public/`) را zip کنید، در File Manager داخل ریشه‌ی سایت آپلود و Extract کنید. `index.html` باید مستقیم در ریشه باشد، نه داخل یک زیرپوشه.
5. **SSL ← Let's Encrypt** را بگیرید و **Force HTTPS** را روشن کنید.
6. (اختیاری) در Config سایت: `error_page 404 /404.html;`

> اگر فایل‌ها را روی کامپیوتر با دوبار کلیک باز کنید، ممکن است فونت وزیرمتن نمایش داده نشود (محدودیت مرورگر برای `file://`). روی هاست درست نمایش داده می‌شود.

## ۳. اینماد

- **تأیید دامنه:** اگر اینماد کد را به‌شکل متا تگ داد، در `index.html` بالای صفحه کامنت «کد تأیید دامنه‌ی اینماد» را پیدا کنید، تگ را از کامنت بیرون بیاورید و کد را جای `ENAMAD_CODE` بگذارید. اگر فایل داد، همان فایل را در ریشه‌ی سایت آپلود کنید.
- **نماد اعتماد:** بعد از صدور نماد، کدی را که پنل اینماد می‌دهد در `index.html` داخل `<div class="trust-seal">` در فوتر بچسبانید.

چک‌لیست پیش از ثبت درخواست:

- [ ] دامنه‌ی ‎.ir در ایرنیک به نام خود متقاضی ثبت شده باشد.
- [ ] نشانی، کد پستی و نام روی سایت دقیقاً با اطلاعات ثبت‌شده در اینماد یکی باشد.
- [ ] هیچ `{{...}}` یا متن آزمایشی روی سایت نمانده باشد.
- [ ] سایت با `https://` و از اینترنت داخل ایران باز شود.
- [ ] اعداد قوانین (مهلت ۲۴ ساعته‌ی اعلام خرابی، بازگشت وجه ظرف ۳ روز کاری، پاسخ به شکایت ظرف ۳ روز کاری) با رویه‌ی واقعی‌تان یکی باشد؛ در غیر این صورت در `terms.html` اصلاح کنید.

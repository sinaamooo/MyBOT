# MyBOT – ربات همه‌کاره کریپتو و مدیریت گروه تلگرام

ربات پایتونی (aiogram 3 / Bot API 10.3) با قیمت‌گیری و تبدیل ارز، چکر ولت و هش روی همه شبکه‌ها، قیمت گیفت‌های تلگرام، ابزارهای ضد کلاهبرداری و مدیریت گروه، و پشتیبانی کامل از **ایموجی پریمیوم** و **دکمه‌های شیشه‌ای رنگی**.

## 🚀 راه‌اندازی

```bash
git clone https://github.com/sinaamooo/MyBOT.git
```

```bash
cd MyBOT && python3 -m venv .venv && . .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

فایل `.env` را باز کنید و حداقل این دو مقدار را پر کنید:

```
BOT_TOKEN=توکن ربات از BotFather
ADMIN_IDS=6595849261
CHANNEL_URL=https://t.me/your_channel
```

اجرا:

```bash
python main.py
```

> نیازمند Python 3.10+ . اگر سرور داخل ایران است، در `.env` مقدار `PROXY` را تنظیم کنید (http یا socks5).

### اجرای دائمی با systemd (لینوکس)

```ini
# /etc/systemd/system/mybot.service
[Unit]
Description=MyBOT
After=network-online.target

[Service]
WorkingDirectory=/opt/MyBOT
ExecStart=/opt/MyBOT/.venv/bin/python main.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now mybot
```

## ⚙️ تنظیمات مهم در BotFather و گروه

1. **Group Privacy را خاموش کنید**: `BotFather → /mybots → Bot Settings → Group Privacy → Turn off` (برای اینکه ربات همه پیام‌های گروه را ببیند).
2. ربات را در گروه **ادمین** کنید (حذف پیام + محدود کردن اعضا) تا ضد سلف/تبچی/عضویت اجباری کار کند.
3. برای عضویت اجباری، ربات باید در **کانال‌ها هم ادمین** باشد.
4. **ایموجی پریمیوم**: طبق Bot API 9.4+ اگر **صاحب ربات تلگرام پریمیوم داشته باشد**، ربات می‌تواند در پیام‌های پیوی و گروه و روی دکمه‌ها ایموجی پریمیوم بفرستد. اگر تلگرام قبول نکند، ربات خودکار همان پیام را با ایموجی معمولی می‌فرستد (چیزی خراب نمی‌شود).

## 🛠 پنل مدیریت (`/panel` در پیوی ربات)

- **📝 متن‌ها**: همه متن‌های ربات (قیمت، تبدیل، چکر ولت، هش، گیفت، هشدارها، ترجمه، اکانت و ...) قابل ویرایش است. متن جدید را با هر فرمتی (بولد، نقل‌قول، ...) و **ایموجی پریمیوم** بفرستید. متغیرها مثل `{toman}` نمایش داده می‌شوند؛ اگر متغیری خالی باشد کل آن خط خودکار حذف می‌شود.
- **🔘 دکمه‌ها**: متن، ایموجی پریمیوم (`icon_custom_emoji_id`) و رنگ (آبی/سبز/قرمز) هر دکمه شیشه‌ای.
- **😎 ایموجی پریمیوم**: برای هر ایموجی معمولی یک ایموجی پریمیوم تعریف کنید تا در **همه** متن‌ها و دکمه‌ها خودکار جایگزین شود.
- **📢 عضویت اجباری**: افزودن/حذف کانال (یوزرنیم، آیدی عددی یا فوروارد پیام از کانال)، روشن/خاموش برای گروه و پیوی.
- **⚙️ تنظیمات**: روشن/خاموش همه قابلیت‌ها، نرخ دستی تتر، قیمت استار، حداقل مبلغ هشدار جابجایی، مدت سکوت سلف و تبچی، لینک کانال، کلمات اضافه ضدکلاهبرداری.
- **🚨 گزارش‌ها**، **📊 آمار**، **📣 ارسال همگانی** (کاربران / گروه‌ها).

دستورات مدیر: `/setrate 0` (نرخ خودکار تتر)، `/addbalance USER_ID AMOUNT`، `/unscam ID`.

ادمین‌های هر گروه هم با `/settings` می‌توانند قابلیت‌ها را فقط برای گروه خودشان روشن/خاموش کنند.

## 🔑 کلیدهای اختیاری

همه چیز بدون کلید کار می‌کند؛ کلیدها فقط محدودیت درخواست را بالا می‌برند: `TRONGRID_API_KEY`، `TONAPI_KEY`، `TONCENTER_API_KEY`، `COINGECKO_API_KEY`، `WHALE_ALERT_API_KEY` (هشدار جابجایی روی همه شبکه‌ها)، `PORTALS_AUTH` (کف قیمت زنده گیفت از Portals).

`API_ID` و `API_HASH` (از my.telegram.org): اگر تنظیم شوند، `/gift @username` برای **هر** کاربری کار می‌کند؛ بدون آن‌ها کاربر باید قبلا در گروهی که ربات هست پیام داده باشد یا ربات را استارت کرده باشد (یا روی پیامش ریپلای کنید).

## 📁 ساختار پروژه

```
main.py                  نقطه شروع
app/bot.py               ساخت ربات، روترها، fallback ایموجی پریمیوم
app/texts.py             متن‌ها و دکمه‌های پیش‌فرض (قابل ویرایش از پنل)
app/handlers/            هندلرها (ادمین، ابزارها، گیفت، کلاهبردار، تنظیمات گروه، روتر متن)
app/middlewares/         ثبت کاربران، محافظ گروه، عضویت اجباری
app/services/            قیمت‌ها، ارزها، کیف پول، تراکنش، گیفت، ترجمه، هشدار نهنگ، کارت‌ها
assets/                  فونت وزیرمتن و پرچم کشورها
tests/                   تست‌ها (pytest)
```

اجرای تست‌ها:

```bash
pip install pytest && python -m pytest -q
```

## 📝 نکات

- تاریخ ساخت اکانت از روی آیدی عددی **تخمین** زده می‌شود (تلگرام تاریخ دقیق را به ربات‌ها نمی‌دهد).
- تلگرام موجودی استارز کاربران را به ربات‌ها نمی‌دهد؛ «موجودی» در `/account` موجودی داخلی ربات است که مدیر با `/addbalance` تنظیم می‌کند.
- قیمت گیفت‌ها از کف قیمت مارکت‌ها (Portals، GetGems، MRKT) محاسبه می‌شود؛ ارزش هر گیفت = بیشترین کف بین کالکشن، مدل، بک‌دراپ و سیمبل آن.
- لایسنس فونت وزیرمتن: `assets/fonts/OFL.txt` — پرچم‌ها از flag-icons (MIT).

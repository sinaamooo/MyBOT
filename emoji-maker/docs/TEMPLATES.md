# قالب‌های آماده‌ی پریمیوم (ایموجی‌های متحرک حرفه‌ای)

قالب‌ها از ایموجی‌های متحرک اصلی ساخته شده‌اند: لوگو و متن برند اصلی کاملاً حذف شده و جای آن
«جایگاه» (Slot) خالی گذاشته شده تا هر خریدار **لوگو یا متن خودش** را بگذارد و **رنگ برند خودش**
را انتخاب کند. هیچ اثری از برند اصلی باقی نمی‌ماند، پس خروجی هر خریدار مخصوص خودش است.

## حرکت‌ها دقیقاً همان می‌ماند

* فایل انیمیشن اصلی هرگز بازسازی یا دوباره‌کلیدفریم نمی‌شود؛ فقط عناصر برند حذف و محتوای
  کاربر اضافه می‌شود. زمان‌بندی، شتاب حرکت‌ها، پرش، چرخش، سایه‌ها، براقی‌ها و ماسک‌ها دست
  نخورده باقی می‌مانند.
* محتوای کاربر داخل همان گروه/لایه‌ای قرار می‌گیرد که لوگوی اصلی بود، پس **دقیقاً مثل لوگوی اصلی
  حرکت می‌کند** (بزرگ‌شدن، چرخیدن، برگشتن، تکان خوردن...).
* خروجی WEBM با یک موتور رندر Lottie کاملاً PHP ساخته می‌شود که با موتور خود تلگرام (rlottie)
  مقایسه شده است: اختلاف میانگین پیکسل‌ها روی هر ۸۴ قالب حدود ۱ از ۲۵۵ است (تقریباً فقط
  لبه‌نرمی). خروجی TGS خودِ انیمیشن اصلی است و تلگرام آن را مثل قبل اجرا می‌کند.

## جایگاه‌ها

* **اصلی (main):** لوگو یا متن اصلی کاربر، به اندازه و محل لوگوی اصلی.
* **زیرنویس (caption):** در قالب‌هایی که زیر لوگو یک خط نام برند داشتند، یک خط متن کوتاه
  (مثلاً نام کانال خریدار).
* اگر کاربر لوگو بدهد، لوگو در جایگاه اصلی و متن او در زیرنویس قرار می‌گیرد؛ اگر فقط متن بدهد،
  متن در جایگاه اصلی می‌نشیند.

## تغییر رنگ

* **فقط رنگ برند (main):** رنگ اصلی قالب (مثلاً آبی) به رنگ انتخابی کاربر می‌رود، بقیه‌ی رنگ‌ها
  دست نمی‌خورند.
* **همه‌ی رنگ‌ها (all):** همه‌ی بخش‌های رنگی با هم جابه‌جا می‌شوند.
* **سیاه‌وسفید (gray).**
* تغییر رنگ در فضای رنگی ادراکی OKLCH انجام می‌شود تا سایه‌روشن، براقی و گرادیان‌ها حفظ شوند.
* **رنگ‌های حساس همیشه پیش‌فرض می‌مانند:** صورت و پوست، چشم، کاراکترها (قورباغه، اردک، خرس...)،
  طلا و سکه، آتش، لوگوی برندهای دیگر. سیاه/سفید/خاکستری و رنگ پوست به‌طور خودکار محافظت
  می‌شوند و بقیه برای هر قالب جداگانه علامت خورده‌اند (`recolor.protect`).
* رنگ‌های اصلی برند پیش‌فرض خریدار نیست؛ تنظیم `templates_original_colors` در پنل:
  `admin` (پیش‌فرض: فقط مدیر ربات)، `all` یا `none`.
* پیش‌نمایش‌های گالری با رنگ `templates_demo_color` نمایش داده می‌شوند.

## ساختار فایل‌ها

```
resources/templates/<pack>/pack.json        نام فارسی و ترتیب بسته
resources/templates/<pack>/<slug>.tgs       انیمیشن اصلی (هرگز ویرایش نمی‌شود)
resources/templates/<pack>/<slug>.json      مشخصات قالب (حذف‌ها، جایگاه‌ها، تغییر رنگ)
resources/templates/<pack>/previews/        پیش‌نمایش‌های گالری
storage/templates/<pack>/...                بسته‌هایی که مدیر از پنل وارد کرده
```

## افزودن بسته‌ی جدید

از پنل مدیریت ← «قالب‌ها» ← «وارد کردن بسته» یک فایل ZIP شامل فایل‌های `.tgs` (یا JSON لاتی)
آپلود کنید، یا در خط فرمان:

```bash
php bin/templates.php import pack.zip --pack=mypack --name="نام بسته" --into=storage
php bin/templates.php sheet --pack=mypack --mode=sample --out=/tmp/sheet.png   # بررسی سریع
php bin/templates.php strip mypack-01 --out=/tmp/s.png --frames=8              # بررسی دقیق یک قالب
php bin/templates.php previews --pack=mypack                                   # ساخت پیش‌نمایش گالری
```

سیستم لوگوی تکرارشونده‌ی بسته را با «اثر انگشت» مسیرها و هم‌رخدادی آن‌ها در همه‌ی انیمیشن‌های
بسته پیدا می‌کند، آن را حذف و جایگاه می‌سازد (وضعیت `auto`). قبل از فعال‌سازی برای فروش، هر قالب
را با دستور `strip` (ردیف‌های: اصلی / حذف‌شده / نمونه متن / نمونه لوگو در چند فریم) بررسی کنید؛
راهنمای کامل بررسی: `docs/dev/TEMPLATE_REVIEW.md`.

قالب‌هایی که خودشان هویت برند هستند (مثلاً کل انیمیشن، لوگوی برند است) غیرفعال می‌شوند.

# 🛍️ سیستم خرید و فروش اعضای تلگرام

یک سیستم جامع و قدرتمند برای خرید و فروش اعضای کانال‌های تلگرام با ربات‌های فرعی و پنل مدیریت حرفه‌ای.

## ✨ ویژگی‌های کلیدی

### 🤖 ربات اصلی
- **منوی اصلی شیشه‌ای** - دکمه‌های جذاب با ایموجی‌های پریمیوم
- **سیستم موازنه حساب** - مدیریت دقیق موجودی کاربران
- **تاریخچه تراکنش‌ها** - ثبت کامل تمام خریدها و فروش‌ها
- **تنظیمات کاربر** - تغییر روش پرداخت و اطلاعات تماس

### 💼 ربات‌های فرعی
- **قفل/باز کردن کانال‌ها** - مدیریت عضویت اجباری
- **سیستم دسترسی** - کنترل دقیق عضویت‌های خریده شده
- **هماهنگی با ربات اصلی** - دریافت اطلاعات از سیستم مرکزی

### 💳 سیستم پرداخت
- **تتر (USDT)** - پرداخت‌های بین‌المللی
- **ترون (TRX)** - تراکنش‌های فوری
- **تومی** - سیستم محلی

### 📊 پنل مدیریت
- **داشبورد آماری** - نمایش کل درآمد، کاربران، خریدها
- **مدیریت کاربران** - مشاهده و کنترل اطلاعات کاربران
- **مدیریت ربات‌های فرعی** - افزودن و حذف ربات‌های زیرمجموعه
- **مدیریت کانال‌ها** - تعیین کانال‌های اجباری
- **گزارش‌های فروش** - تحلیل فروش و درآمد
- **تنظیمات سیستم** - کنترل تمام پارامترهای سیستم

## 🚀 نصب و راه‌اندازی

### الزامات
- PHP 7.4+
- MySQL 5.7+
- cURL
- Shell Access

### مراحل نصب

#### 1. بارگیری فایل‌ها
```bash
git clone <repository-url> mybot
cd mybot
```

#### 2. پیکربندی
ویرایش فایل `src/config/config.php` و تنظیم:
```php
define('BOT_TOKEN', 'YOUR_BOT_TOKEN');
define('ADMIN_ID', YOUR_ADMIN_ID);
define('DB_HOST', 'localhost');
define('DB_USER', 'your_db_user');
define('DB_PASS', 'your_db_password');
define('DB_NAME', 'telegram_shop');
define('WEBHOOK_URL', 'https://yourdomain.com/bot.php');
```

#### 3. اجرای نصب‌کننده
```bash
php install.php
```

اسکریپت نصب مراحل زیر را انجام می‌دهد:
- ✅ اتصال به دیتابیس
- ✅ ایجاد دیتابیس
- ✅ ایجاد جداول
- ✅ ایجاد کاربر مدیریت
- ✅ ایجاد دایرکتوری‌های مورد نیاز
- ✅ تست اتصال ربات

#### 4. تنظیم Webhook
```bash
# اجرای این دستور در terminal (جایی که curl موجود است)
curl -X POST https://api.telegram.org/bot[BOT_TOKEN]/setWebhook?url=https://yourdomain.com/bot.php
```

## 💾 دیتابیس

### جداول اصلی

#### users
- telegram_id: شناسه تلگرام کاربر
- first_name: نام اول
- username: نام‌کاربری تلگرام
- phone: شماره تلفن
- balance: موجودی حساب
- payment_method: روش پرداخت
- status: وضعیت (فعال/غیرفعال)

#### purchases
- buyer_id: خریدار
- members_count: تعداد اعضا
- price: قیمت
- payment_method: روش پرداخت
- status: وضعیت (در انتظار/تکمیل شده)

#### sales
- seller_id: فروشنده
- members_count: تعداد اعضای در دسترس
- price_per_member: قیمت به ازای هر عضو
- profit_percentage: درصد سود
- status: وضعیت (در دسترس/فروخته شده)

#### sub_bots
- bot_token: توکن ربات فرعی
- bot_name: نام ربات
- owner_id: مالک
- status: وضعیت فعالیت

#### channels
- sub_bot_id: ربات فرعی
- channel_id: شناسه کانال
- is_mandatory: آیا اجباری است؟

## 🐛 حل مسائل

### مشکل: "Connection failed"
- بررسی اتصال MySQL
- بررسی نام کاربری و رمز عبور دیتابیس
- بررسی وجود دیتابیس

### مشکل: "Bot connection failed"
- بررسی صحت توکن ربات
- بررسی دسترسی اینترنت
- بررسی وضعیت سرور تلگرام

### مشکل: Webhook غیرفعال
```bash
# بررسی وضعیت webhook
curl https://api.telegram.org/bot[BOT_TOKEN]/getWebhookInfo
```

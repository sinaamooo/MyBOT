# 🚀 ربات فروش ممبر + دو مینی‌اپ

ربات فروش ممبر (سورس اصلی) با دو **مینی‌اپ کاملا جدا از هم** روی همان ربات:

| مینی‌اپ | آدرس | تم گرافیکی | چه می‌فروشد |
|---|---|---|---|
| 🌟 **خدمات تلگرام** | `?app=tg` | شفق قطبی — بنفش/فیروزه‌ای، شیشه‌ای، ستاره‌های متحرک | استارز، پریمیوم، گیفت، تون، ترون |
| 🛡 **فروش کانفیگ** | `?app=cfg` | سایبر گرید — مشکی/نئون، شبکه پرسپکتیو، فونت مونو | سرویس حجمی، نامحدود، آی‌پی اختصاصی |

دکمه هر دو مینی‌اپ **دقیقا زیر دکمه‌های ثبت سفارش محصولات** می‌نشیند (و بالای دکمه «لیست تعرفه‌ها»).

## فایل‌ها

```
bot_master_membership.php   ربات اصلی (وبهوک) — سورس فروش ممبر + قلاب‌های مینی‌اپ
miniapps.php                منطق مینی‌اپ‌ها: پیکربندی، API، سفارش، پرداخت، پنل مدیریت
miniapp_view_tg.php         ظاهر مینی‌اپ خدمات تلگرام
miniapp_view_cfg.php        ظاهر مینی‌اپ فروش کانفیگ
```

هر چهار فایل باید کنار هم در یک پوشه باشند. نیازی به دیتابیس یا کتابخانه بیرونی نیست
(PHP 7.4+ با `curl`)؛ داده‌ها در `data_master/` به صورت JSON ذخیره می‌شوند.

## راه‌اندازی

۱. هر چهار فایل را روی هاست آپلود کنید و مطمئن شوید وب‌سرور اجازه نوشتن در پوشه را دارد.

۲. وبهوک را ست کنید:

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://DOMAIN/bot_master_membership.php
```

۳. داخل ربات `/panel` را بزنید → **🚀 مینی اپ‌ها** → **🔗 آدرس عمومی** و آدرس کامل همین فایل را بفرستید:

```
https://DOMAIN/bot_master_membership.php
```

> ⚠️ آدرس حتما باید **https** باشد — تلگرام مینی‌اپ روی http را باز نمی‌کند.
> تا وقتی این آدرس ثبت نشود، دکمه مینی‌اپ‌ها اصلا نمایش داده نمی‌شود.

۴. تمام. `/start` → «خرید محصول» → دکمه‌های مینی‌اپ زیر محصولات دیده می‌شوند.

## پنل مدیریت — `/panel` ← 🚀 مینی اپ‌ها

برای **هر مینی‌اپ جداگانه**:

- **🎨 دکمه زیر محصولات** — متن، ایموجی، **رنگ** (آبی/سبز/قرمز)، ایموجی پریمیوم، ترتیب نمایش
- **🖌 تم و رنگ گرافیکی** — رنگ اصلی، رنگ دوم، رنگ تاکید، پس‌زمینه (`#RRGGBB`)، درخشش، بافت
  - **🎭 پالت‌های آماده**: بنفش کهکشانی، نئون سایبری، غروب آتشین، اقیانوس عمیق، طلایی رویال، قرمز خونی، مینت یخی، سفید مینیمال
- **✏️ متن‌های مینی‌اپ** — عنوان، زیرعنوان، شعار، یادداشت فاکتور، واحد پول و متن تک‌تک دکمه‌های داخل اپ
- **💠 متن و رنگ دکمه‌های شیشه‌ای** — دکمه‌های فاکتور داخل ربات (پرداخت کیف پول، کارت به کارت، ارسال رسید، انصراف، باز کردن مینی‌اپ): متن، ایموجی، **رنگ** و ایموجی پریمیوم هرکدام جدا
- **📂 دسته‌ها** — همان تب‌های بالای مینی‌اپ (افزودن، نام، ایموجی، خاموش/روشن، حذف)
- **🛒 سرویس‌ها** — نام، ایموجی، قیمت، توضیح، برچسب، دسته، ترتیب، خاموش/روشن، حذف
  - **❓ نوع سوال**: بدون سوال · آیدی تلگرام · تعداد (قیمت × تعداد با حداقل/حداکثر) · آدرس ولت · توضیح دلخواه
- **🧪 پیش‌نمایش** — دکمه واقعی مینی‌اپ برای تست
- **🧾 سفارش‌ها** — سفارش‌های در انتظار تایید و آماده تحویل

تنظیمات دو مینی‌اپ کاملا از هم جدا نگهداری می‌شود؛ تغییر یکی روی دیگری اثری ندارد.

## مسیر سفارش

```
کاربر در مینی‌اپ سرویس را می‌زند
        ↓
سرور initData تلگرام را با HMAC بررسی می‌کند (جعل‌ناپذیر) و قیمت را خودش حساب می‌کند
        ↓
فاکتور داخل ربات فرستاده می‌شود
        ↓
💰 پرداخت از کیف پول            💳 کارت به کارت
   (اگر موجودی کافی باشد)          → ارسال رسید → تایید ادمین
        ↓                                ↓
        └────────── سفارش «پرداخت‌شده» ──────────┘
                          ↓
        ادمین با «📤 تحویل سفارش» کانفیگ/کد/لینک را می‌فرستد
                          ↓
              همان محتوا برای کاربر ارسال و سفارش بسته می‌شود
```

نکات امنیتی:

- قیمت هیچ‌وقت از سمت کاربر خوانده نمی‌شود؛ همیشه روی سرور از روی پیکربندی حساب می‌شود.
- `initData` با `HMAC-SHA256` و توکن ربات بررسی می‌شود؛ امضای دستکاری‌شده، جعل آیدی و
  داده قدیمی‌تر از ۲۴ ساعت رد می‌شوند.
- فاکتور هر کاربر فقط با همان کاربر پرداخت می‌شود و پرداخت دوباره جلوگیری می‌شود.
- عضویت اجباری و مسدودی کاربر روی سفارش‌های مینی‌اپ هم اعمال می‌شود.
- تایید/رد/تحویل فقط برای ادمین ممکن است.

## آدرس‌های سرویس‌دهی

```
https://DOMAIN/bot_master_membership.php                 وبهوک ربات مادر
https://DOMAIN/bot_master_membership.php?bot=<BOT_ID>    وبهوک ربات‌های اپلودر
https://DOMAIN/bot_master_membership.php?app=tg          مینی‌اپ خدمات تلگرام
https://DOMAIN/bot_master_membership.php?app=cfg         مینی‌اپ فروش کانفیگ
https://DOMAIN/bot_master_membership.php?mapi=1          API مینی‌اپ‌ها (POST + initData)
https://DOMAIN/bot_master_membership.php?cron=<CRON_KEY> صف حذف و بررسی درگاه
```

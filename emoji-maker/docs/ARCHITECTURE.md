# معماری پروژه

```
emoji-maker/
├─ app/                     کد اصلی (PSR-4: EmojiMaker\)
│  ├─ App.php               ریشه‌ی ساخت سرویس‌ها (تنظیمات، دیتابیس، ذخیره‌ساز، رندر، تلگرام، صف)
│  ├─ Text/                 موتور متن خالص PHP: خواندن TTF، شکل‌دهی فارسی (GSUB/GPOS)، راست‌به‌چپ (Bidi)
│  ├─ Geometry/ Rendering/  مسیرها، رسترایزر ضدپله، جلوه‌ها (سایه، درخشش، عمق سه‌بعدی، قاب‌ها)
│  ├─ Animation/            ۲۱ افکت حرکتی + ترکیب‌ها، خط زمان، حلقه‌ی بی‌درز
│  ├─ Batch/                برنامه‌ریز پک چندتایی بدون تکرار
│  ├─ Vector/               ساخت Lottie (TGS)، ردیاب لوگو، پخش‌کننده‌ی Lottie سازگار با rlottie
│  ├─ Templates/            قالب‌های آماده: تشخیص لوگو، جایگاه‌ها، ترکیب محتوا، تغییر رنگ OKLCH
│  ├─ Encoding/             WEBM (VP9+آلفا)، پیش‌نمایش MP4/GIF
│  ├─ Validation/           اعتبارسنجی WEBM/TGS/PNG با قوانین تلگرام
│  ├─ Telegram/             کلاینت Bot API، کیبوردها، انتشار پک ایموجی
│  ├─ Bot/                  وبهوک، مسیریابی به‌روزرسانی‌ها، گفت‌وگوی فارسی و مراحل ساخت
│  ├─ Queue/                صف کار مبتنی بر دیتابیس، کارگر، پردازشگرها (پیش‌نمایش، ساخت، انتشار، تحویل)
│  ├─ Delivery/             ZIP، لینک دانلود امضاشده
│  ├─ Admin/                پنل مدیریت فارسی
│  ├─ Install/              نصب‌کننده
│  ├─ Database/             PDO + مخزن‌ها
│  ├─ Storage/ Security/ Support/ Process/
├─ bin/                     اسکریپت‌های خط فرمان (نصب، کارگر، کرون، پاک‌سازی، وبهوک، قالب‌ها، عیب‌یابی)
├─ config/app.php           تنظیمات و محدودیت‌های رسمی تلگرام
├─ database/                schema.sql، seed.sql
├─ public/                  تنها پوشه‌ی قابل دسترس از وب: webhook.php، download.php، admin/، install/، assets/
├─ resources/               فونت‌ها و قالب‌های آماده
├─ storage/                فایل‌های خصوصی (آپلود، خروجی، موقت، لاگ، نشست‌ها) — بیرون از دسترس وب
├─ deploy/                  نمونه‌ی تنظیمات nginx، Apache، systemd، supervisor، cron
└─ docs/                    راهنماها
```

## جریان کار

1. **تلگرام → وبهوک** (`public/webhook.php`): بررسی توکن مخفی، ثبت `update_id` برای جلوگیری از
   تکرار، پاسخ فوری ۲۰۰ و سپس پردازش (یا سپردن به کارگر در حالت `queue`).
2. **ربات** (`app/Bot`): کاربر را ثبت/به‌روز می‌کند، حالت گفت‌وگو را از دیتابیس می‌خواند، مرحله‌ی
   بعدی را با دکمه‌های شیشه‌ای نشان می‌دهد و تنظیمات پروژه را ذخیره می‌کند. کارهای سنگین هرگز
   داخل وبهوک انجام نمی‌شوند؛ فقط یک «کار» در صف ثبت می‌شود.
3. **صف** (`generation_jobs`): کارگر (`bin/worker.php`، با cron یا systemd) کار را با قفل خوش‌بینانه
   برمی‌دارد، با محدودیت تعداد اجرای هم‌زمان و یک کار فعال برای هر کاربر، پیشرفت را در پیام تلگرام
   نشان می‌دهد، لغو و تلاش مجدد با تأخیر نمایی را پشتیبانی می‌کند.
4. **ساخت**: برای هر مورد، `EmojiRenderer` (طرح‌های ساخته‌شده از متن/لوگو) یا `TemplateRenderer`
   (قالب‌های آماده) فایل نهایی + اعتبارسنجی + پیش‌نمایش می‌سازد؛ فایل‌ها در `storage` ثبت می‌شوند،
   شبکه‌ی پیش‌نمایش و ZIP ساخته و برای کاربر ارسال می‌شود.
5. **انتشار**: پک ایموجی سفارشی با `uploadStickerFile` → `createNewStickerSet` (۵۰ تای اول) →
   `addStickerToSet` (تا ۲۰۰) و ارسال لینک `t.me/addemoji/...`.
6. **پنل مدیریت**: آمار، کاربران، خروجی‌ها، صف، افکت‌ها، قالب‌ها، فونت‌ها، تنظیمات امن، لاگ‌ها.

## چرا PHP خالص؟

هسته‌ی پروژه (شکل‌دهی متن فارسی، رندر، انیمیشن، ساخت TGS، پخش Lottie، اعتبارسنجی، ZIP) بدون هیچ
کتابخانه‌ی خارجی نوشته شده تا روی هاست اشتراکی هم کار کند. تنها وابستگی بیرونی، **FFmpeg** برای
فشرده‌سازی ویدیوی WEBM و پیش‌نمایش MP4 است که از طریق `proc_open` با آرگومان‌های امن اجرا می‌شود.
